# 局部观测下的 NTE＋D：基线建立与后续创新验证计划

日期：2026-10-27。状态：已实施接口验收与教师屏障；实际6/12通过，低于预定7/12，按协议在正式训练前停止。独立测试闭环未启动。[执行报告](current/l45_nte_d_local_baseline_20261027/REPORT.md)。下文保留原计划，部署版本及既有实验结论未改变。

## 1. 目标与研究边界

保留神经网络与 MCTS，将已验收的多模态估计器 D 接入 NTE 式连续动作扩展，研究遮挡后目标位置不确定时的决策。先建立可信的适配基线，再验证针对几何分支的改进。

**全链路以局部观测为前提，包括教师、网络训练和树内决策。** 公开地图可以完整已知；目标状态只能在满足既有距离与遮挡传感器条件时观测。地图已知不等于目标全状态可见。本轮不扩展到未知地图或视觉感知训练。

当前阶段保持 D 的已验收范围：20×20 场地、单目标追捕、直接位移动力学、dt=1、感知半径6、总时域80。沿用已有合法碰撞规则、追逃速度配置和真实 RootPUCT3000 对手。对手原有信息条件单独记录，各追捕方法面对相同对手；本轮不声称双方均为局部观测。

本阶段只建立和评估 **NTE＋D 适配基线**，暂不训练新的几何分支生成网络。计划默认恢复策略与价值两个原框架组件；二者的作用分别消融，不把恢复原组件算作创新。它们属于本计划建议，本文落盘不代表已经开始训练。

NTE 原文包含全信息专家、局部 learner、连续动作神经扩展及策略/价值学习。本计划将专家也限制为公开历史和信念，并使用当前追捕任务，因而称“局部信念 NTE 适配”，不称原论文的完整复现。[NTE 原文](https://arxiv.org/html/2104.09705v3)

## 2. 必须冻结的信息接口

流程：公开地图与合法历史 → 冻结 D → 带权64样本 → 公共信念编码 → 神经动作扩展 → 有限预算 MCTS → 合法动作。

|模块|允许读取|禁止读取|
|---|---|---|
|D、策略网络、价值网络|公开地图、自身状态、时间、可见目标测量、合法历史、由上述信息形成的信念|不可见目标真值、未来轨迹、真实对手的内部搜索状态|
|教师搜索|同一公共接口；允许更多离线计算|特权目标坐标、按真实目标挑选假设或动作|
|树内动作与 rollout|模拟自身状态、模拟传感器已公开的信息及相应条件信念|绕过传感器直接使用采样目标坐标追踪|
|模拟器|从当前信念采样的状态、固定运动模型，用于产生模拟观测与回报|用真实隐藏目标替换信念采样、将采样状态暴露给 actor|
|真实环境与事后评价|推进环境、判定合法捕获、计算评价指标所需真值|把评价数据回流到在线策略或测试调参|

冻结目录：`current/l45_corner_turn_estimator_20261025/frozen_estimator`；校验其源文件散列，通过已有 loader 加载。保留64样本的非均匀权重，不转成等权，不只保留均值点。

树内复用已审计的固定根图目标运动核与观测条件更新。它是规划近似，并不声称逐步等同于 D 的全部在线重建行为；在线正观测后的重建与再次遮挡成本必须保留。不得把看不见目标解释为捕获或提前结束。

网络使用无序集合编码：样本的位置和权重、地图几何、自身状态和公开观测历史。样本顺序置换不应改变输出分布；不输入教师分数、访问次数标签或样本与真值的距离。网络参数与推理接口在测试前冻结。

## 3. 本阶段实施顺序

### A. 先完成基线与接口验收

独立目录建议为 `current/l45_nte_d_local_baseline_20261027`。旧权重、旧教师标签和旧候选评分器不得直接作为已验收的 NTE 基线；需要重新核对输入、动作与监督语义。

恢复的核心是：策略网络在树扩展时生成连续动作，渐进增加可用动作，并与均匀动作提议混合；价值网络用于相同剩余规划时域的叶节点评价。不能只改变根候选的评分并将其改称 NTE。树节点按公共动作—观测历史区分，所有实验臂共用这一适配方式。

沿用当前深度8、折扣0.95、重发现与捕获奖励、合法几何 rollout 和目标模型。本轮不同时研究深度或奖励。策略与价值使用小型集合编码器；策略输出单个对角高斯的连续动作分布，价值输出同一有限时域回报。暂不加入多峰网络、注意力、PPO或新辅助损失。具体层宽、动作变换、渐进扩展公式及训练参数须在生成正式标签前写入机器可读配置并计算散列，不在测试后选择。

接口验收至少包括：

1. 权重有限、非负且归一化；采样频率与权重一致；输入集合置换不改变确定性推理结果。
2. 连续动作通过幅度、边界和整段碰撞检查；拒绝采样次数有上限；失败回退为合法停止动作，并统计回退率，不能偷偷回退到G提高成绩。
3. 固定公共历史与随机流，替换不可见真实世界状态，公共输入、网络输出和固定模拟次数搜索结果应一致。
4. 在不同采样世界共享相同模拟观测前缀时，追捕策略条件相同；只有获得不同合法观测后才允许分支。
5. 固定模拟次数可重放；按时间截断的运行不要求访问次数逐位一致，保留实际次数、随机种子和时间轨迹。
6. 无非法转移或遮挡导致的假终止；模型输入、训练标签来源和真实环境字段做独立审计。

发现真值泄漏、非法动作或错误终止即停止。修复仅使用训练/开发数据，重新验收后才能生成正式数据。

### B. 有限训练，先验证监督是否值得学习

建议计算上限为实现与单元验收完成后的 **6小时流水线墙钟时间**，包括正式数据生成、训练、闭环评估与审计；另外记录 CPU/GPU 时数、线程数与峰值内存。该数值是计划默认值，不是已发生的耗时。到期保存状态并报告未完成，不自动扩容。

初始规模固定为24张训练地图、6张验证地图、18张测试地图，每类包含困难遮挡、墙角和多通路。按完整地图及其所有历史划分；旧实验地图/历史均不得进入新测试集。正式测试18组公共初始历史、每组两个隐藏世界，两个世界与训练种子都不是额外独立样本。

训练种子17、29、43，每个最多30个epoch；只做一轮搜索监督训练，不自动启动迭代自博弈。训练公共状态至多768个、验证至多192个，按地图平衡并包含目标可见、刚丢失与持续遮挡阶段。采集行为使用冻结G与合法随机探索的预定混合，完整轨迹归属一个分区。不得从测试局采集标签。

离线教师使用同一公共信念、奖励和模型，单次完整查询上限2秒；在线完整决策上限200ms。先用开发数据检查增加计算是否改善候选评价的稳定性及实际决策，不能默认高预算等于好教师。教师只产生当前信念模型下的监督，不读取真实未来。

策略监督来自该教师的连续扩展动作统计，明确记录采用访问加权动作目标的规则及碰撞投影影响；价值监督使用同一公共信念模型的独立模拟回报，不以真实隐藏状态构造特权输入。监督必须保存访问分布、回报方差与有效样本数，不能只保留一条“最优”动作。训练前在开发地图检查教师排序的重复采样稳定性；若多数状态的动作差异小于模拟不确定性，停止并报告教师信号不足，不强行制造确定标签。

不要求教师先超过G才能做框架验收，但不能将不可靠教师训练出的模型称为成熟NTE基线。若训练/验证损失未稳定、教师信号弱或模拟预算不足，本轮只能形成工程试验结果，不能以它作为后续论文的弱基线。

### C. 冻结检查点后，开展一次独立闭环评估

|组别|在线方式|主要回答的问题|
|---|---|---|
|G＋D|已有强几何策略|实际任务参考水平与计算代价|
|M0＋D|同一搜索，均匀连续动作扩展，无价值网络|无学习的匹配搜索基线|
|Nπ＋D|策略引导扩展，无价值网络|学习动作扩展相对M0是否有效|
|NπV＋D|相同策略检查点，启用价值网络|原框架价值组件是否提供增益|
|π-direct＋D|同一策略检查点直接生成动作，无搜索|搜索相对网络直接控制是否有效|

后三组分别报告三个训练种子。Nπ与NπV共用同一策略检查点，仅在推理时切换价值组件；这是组件使用消融，不宣称已经比较各变体独立重训后的最优性能。直接策略采用固定种子的合法条件采样，不用隐藏真值或G评分选择样本。

18组×2个世界×11个执行臂，最多396局。测试清单提前封存，全部模型冻结后只运行一次；不得看部分测试结果再调参。真实对手使用同一版本、公共初态和约定随机流，不能预读追捕者本步动作。闭环分歧后各组自身历史自然不同，不强行复用其他组未来观测。

所有组使用相同动作约束、任务终止与信息条件；三种搜索共享奖励、树深度、目标核、树选择及rollout，差异严格限定为网络扩展和叶值开关。目标可见阶段统一使用已有几何追踪，因此本轮结论聚焦遮挡决策，不能外推为全程神经控制的收益。

完整200ms包含地图/模型/历史初始化、D更新、样本导出、特征、网络、搜索、合法性检查和回退。首次开销真实记在首次决策；另报摊销值，不用摊销掩盖首次或重新遮挡后的超时。预热与编译独立列出。G无需等待用满预算。真实对手和环境耗时另列，并报告联合高层周期；dt=1是仿真步长，不能直接解释为硬件允许1秒计算。

在线时延串行实测，训练或离线标签生成的并行耗时不得替代。记录每步实际总耗时、分项、P50/P95/P99/最大值、超时率、有效模拟数和回退率。预算保护失败也保留该局，不删除慢局和失败局。

## 4. 评价、停止与结论口径

主要任务指标为失败计入的完成成本：合法捕获使用接管后的实际步数；未捕获使用接管时剩余步数。并列报告合法捕获率、重发现率、失败计入的重发现成本、成功条件下的重发现时间及完整时延。成功局步数不能替代全体成本。

三项预定主要比较为：Nπ−M0、NπV−Nπ、NπV−π-direct。完成成本越低越好。按18组公共初始历史成组配对bootstrap 10,000次，保留组内所有世界与种子，采用三项同时95%置信区间；种子结果单列，不挑最佳种子。G比较及各拓扑结果完整报告，作为任务参考和描述性诊断。

对某一组件称“可靠收益”需同时满足：对应成本差区间上界小于0、平均至少改善1步、三个训练种子平均方向一致、无观察到的合法捕获率下降，以及信息隔离与合法性审计通过。捕获率未下降仅是观察护栏，不等于统计非劣证明。超时结果单独决定是否满足200ms工程要求，不能把超预算收益称为同预算收益。

区间跨0称“证据不足”；区间整体大于0称“当前配置成本变差”。不显著不代表等效，也不能推出NTE或MCTS普遍无效。训练损失下降不作为闭环收益证据。

本阶段结束后：

- 若基线接口可靠、训练有可用监督，且学习扩展或搜索显示稳定正向作用，可提出下一阶段的机制试验。
- 若仅价值组件无收益，记录消融；不自动叠加其他网络或在测试集上替换结构。
- 若教师不可靠、训练明显不足或测试不完整，报告基线未建立充分，不能据此宣布改进胜过NTE。
- 若学习扩展与搜索均无可靠收益，结束本轮；仅做公开日志支持的失败分析，不追加epoch、搜索深度或测试重调。
- 不要求本阶段所有组件都超过G，但任何论文或报告均同时展示G。相对NTE的改善不等于相对所有方法最优，更不自动构成会议录用意义上的创新。

## 5. 后续创新路线与论文主张

只有完成当前阶段后，再设计独立协议检验“几何分支条件下的神经动作扩展”：D保留墙体两侧与多通路假设；网络按公共信念和可达几何生成不同路线的动作；MCTS在固定计算内评价这些动作。首先检验单高斯扩展是否遗漏重要合法路线，不能预设它就是失败原因。

后续需要比较同条件NTE＋D原始扩展、手工几何扩展、通用多峰扩展与提出的方法，匹配训练数据、参数量及实际预算。收益须来自可验证的几何机制，而不是多给候选、计算或监督。新的几何生成网络不在当前阶段训练。

D的贡献另行区分：当前各组都用D，不能从本轮组间差异证明D本身带来了闭环收益。后续用同一决策器比较D与合法的均匀可行集合、经修复验收的原64粒子参考，并按各自输入重新训练或明确做冻结模型的输入替换诊断。均匀集合若共享D的支持，只能隔离概率质量，不能声称隔离了D的全部作用。不能用“目标消失就停止”的伪无估计器基线夸大收益。

论文候选问题为“遮挡追捕中，利用多模态位置信念改善有限预算神经树扩展”。是否新颖仍需相对NTE及信念条件动作生成等相关方法核对；“加一个估计器”或“比某个NTE适配版本强”本身不充分。当前结果只覆盖已知拓扑的新实例、单目标和固定对手；新对手、多机器人、噪声及实机属于之后另行设计的验证，不提前写成已证实能力。
