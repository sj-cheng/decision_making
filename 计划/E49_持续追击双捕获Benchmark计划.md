# E49：速度劣势下、追捕者持续行动的 2v2 双捕获 Benchmark（修订计划）

状态：**2026-11-09 用户已批准实施，工程实现与验收进行中，正式评测尚未启动。** 2026-11-08 已确认地图总量选择 A：84 张。以下合入过程采样捕获、同一大步连续多捕、三档障碍，以及根据开发集饱和情况调整统一总时域的要求。训练地图分档、输入迁移、时域标定阈值和采样复核细节按本计划实施；实时状态见 `current/e49_persistent_pursuit_benchmark_20261108/status.json`。

## 1. 已确认的任务与边界

本轮比较约定的 12 个方法在新规则下的表现，重点观察首捕后保持两名追捕者，能否继续完成第二次捕获。评测目标包括识别方法间差异，以及各方法在追捕效率、首捕后协同、遮挡恢复、多障碍适应和计算成本上的优缺点。先在开发集标定统一总时域，尽量避免双捕率普遍接近满分或零分；区分度不足也如实报告，不预设必须拉开排名。只做新规则主表，不追加退休／不退休对照。新规则同时改变速度、捕获后行动规则、捕获时间判定及无遮挡要求，并扩展障碍数量。

| 项目 | E49 固定规则 |
|---|---|
| 人数与目标 | 2 名追捕者、2 名逃跑者，捕获全部逃跑者算胜利 |
| 追捕速度 | 每轴位移上限 **1.0** |
| 逃跑速度 | 每轴位移上限 **1.5** |
| 捕获条件 | 每个 1 秒动作按 **0.01 秒**采样，在任一采样时刻中心距离严格小于 **1**、且两者之间无遮挡即捕获；起始合法状态也检查 |
| 捕获匹配 | 同一采样时刻沿用距离优先的一对一匹配及既有平局规则；不同采样时刻允许同一追捕者继续捕获第二个目标 |
| 捕获后状态 | 被捕逃跑者立即停止并退出后续目标集合；追捕者继续执行本步剩余动作，始终保留移动和观测能力 |
| 对手 | 适配新规则的 **RootPUCT3000**，保留原深度 100、全状态输入及原奖励配置 |
| 其余条件 | 原 20×20 场地、1 秒物理步长、半径 6 的全周向无遮挡精确共享观测、已知地图 |
| 总时域 | 初始 **80 步**；按开发集标定规则统一缩短或延长，选定 **H** 后用于所有方法、地图档位和正式测试 |
| 执行方式 | 沿用锁步仿真；决策及公共观测仍每秒一次，不因捕获增加决策；搜索采用名义 200 ms，直控按实际耗时返回 |
| 障碍档位 | 原稀疏布局（不超过 8 个障碍）、16 个障碍、24 个障碍 |

本轮不加入相机 FOV、感知噪声、实车动力学、新对手或额外速度扫描。结果用于评价这套新任务，不能单独归因于取消退休或速度比；也不把障碍数量差异直接解释成纯密度因果效应。固定采样可能漏掉极短交会，不能宣称是精确连续碰撞检测。

## 2. 统一规则实现与 12 个方法

建立独立 E49 实现和私有 C++ 模块，保留历史实验源码、二进制、模型及结果。统一任务配置显式传递双方速度、退休开关、捕获遮挡条件和子步间隔，取消通过“速度等于 1”推断阵营的旧逻辑。角色、速度、捕获事件与存活掩码一致进入真实环境和所有前向模拟。

规则必须同时覆盖：

- Python 真实环境与训练环境。
- RootPUCT 的 C++ 内部状态推进、捕获和终止判断。
- 追捕方树内模拟、目标运动模型、信念更新及历史恢复。
- 独立轨迹审计与评分器。

方法固定如下，保留原算法与隐藏层结构，仅做下述输入容量迁移和规则适配：

| 类别 | 方法 |
|---|---|
| 几何控制 | IG、AG、RouteAPF |
| 学习调节几何控制 | MAPPO＋RouteAPF |
| 旧搜索参考 | GEOM_SEARCH、SINGLE_PRIOR |
| 同池搜索 | A1 随机顺序、A2 几何排序、A3/L5 学习排序 |
| 同池直控 | A4 几何最高分、A5 学习最高分 |
| 学习直控 | PPO-C |

具体适配约定：

- AG 在 2v2 时保留原匹配目标；进入 2v1 后，两辆车均追捕剩余目标。RouteAPF 与 MAPPO＋RouteAPF 使用相同分配扩展，保留原队友分离机制，不额外设计包抄角色。
- A1—A5 保留最多 16 个候选、75% 几何／25% 随机的生成规则；相同公共节点使用相同候选数组，排序与搜索随机流分离。
- 所有追捕搜索继续关闭学习叶价值。保留原深度上限、渐进扩展和几何势配置。
- 继续使用公共历史和每目标 64 个带权样本；逃跑速度 1.5 同步进入预测、可达边、噪声及恢复网格，记录这是速度重参数化后的模型。
- 所有方法获得完整地图，特征、观测空间、批处理、导出推理和 C++ 接口的障碍容量统一支持 24；禁止截取前 8 或前 16 个障碍。
- Single、L5、PPO-C 保留逐障碍编码及带掩码求和，仅扩展障碍槽位；不改为平均池化，也不增加隐藏层容量。验证原稀疏输入的预测与旧实现一致。
- MAPPO＋RouteAPF 扩展 actor／critic 的固定长度输入，按语义映射旧特征列、输入层权重及归一化参数；新增输入列采用零权重初始化，其他旧权重热启动。其输入 LayerNorm 覆盖维度改变，因此不能承诺补零后旧输出严格一致；记录迁移前后偏差，再按统一开发规则判断是否补训。不得静默丢弃旧权重或把随机初始化称为冻结迁移。
- 固定任务不新增速度输入；两名追捕者的活动掩码在首捕后仍保持有效，避免沿用退休动作屏蔽。
- 总时域采用显式参数 H，贯通环境终止、双方树内剩余时域、训练截断、历史特征和评分。审计所有硬编码的 80：实际步号由真实时间或 H−remaining 得到，剩余时间特征统一用 remaining/H；H=80 时验证旧特征兼容。观测频率、动作步长和搜索预算不随 H 改变；RootPUCT 原深度上限 100 保留，并受实际剩余时域约束。
- 子步用于判定动作内的捕获事件，不能给任何控制器额外的 100 Hz 感知或决策机会。运动插值、障碍碰撞处理及动作执行路径沿用原运动语义；若无法一致实现，应先报告差异，不自行替换动力学。
- 以预先冻结的小规模工程配对轨迹进行 0.005 秒独立复核，覆盖三档障碍、12 方法和首捕前后；报告事件时间与捕获结果差异。若出现改变捕获集合、终局胜负或显著改变后续路径的差异，暂停正式测试并说明，不能看正式测试成绩后自行换采样规则。

所有历史均重新按 E49 规则重放验收；超出新速度限制的脚本必须重建，禁止仅修改配置中的速度数值。保留合法正观测开始、随后遮挡的共享历史及 AB／BA 两个隐藏世界，不改成开局公布全体目标位置。历史全过程用新速度、无遮挡与 0.01 秒捕获规则验收，不能在历史中发生已捕获却仍列为活动目标的情况。

新地图与历史地图按平移、直角旋转等价几何去重。只按几何、连通性、初态与公共历史合法性接收，不按方法输赢筛选。正式测试不参与适配决策。

**先标定统一总时域，避免普遍满分或零分**

完成规则验收和输入迁移后，先用尚未补训的全部冻结模型，在既有 24 张开发地图上标定 H，再进行后续适配。以下为预先约定的候选范围与判断规则，不按哪个方法领先来选择时域：

- 候选总时域为 **40、60、80、100、120、160 步**，从 80 步开始。全程使用相同地图、两个隐藏世界、一个固定配对随机流和全部 22 个方法实例。
- 先在每个方法内部平均三个模型种子，再按地图和三个障碍档位等权计算双捕率；判断饱和时，12 个方法各占一票，不能让有三个模型的学习方法获得更高权重。
- 若至少 **10／12 个方法双捕率≥90%**，视为普遍过易，依次试 **60、40 步**；若至少 **10／12 个方法双捕率≤10%**，视为普遍过难，依次试 **100、120、160 步**。
- 一旦不再满足上述任一饱和条件，就选择当前 H 并停止。若缩短／延长的相邻档位从普遍过易直接跳到普遍过难，或反向跳变，则保留上一个档位并报告，停止自动调整。若到达候选边界仍饱和，保留边界 H 并如实说明，不继续扩展预算或改规则。
- 若有的方法好、有的方法差，或胜率虽接近但均未触发普遍饱和，保持当前 H；不通过最大化方法胜率方差、显著性或某个方法的优势来挑选 H。
- 对所有方法、障碍档位及正式测试采用同一个 H。每个候选档位重新运行闭环；控制器会读取剩余时间，不能简单裁剪长时域轨迹充当短时域重跑结果。
- 每个候选为 **24×2×1×22＝1,056 局开发评测**，最多访问 4 个候选档位，共至多 4,224 局。标定局数和计算成本单列，不计入 7,392 局正式矩阵；选定档位的冻结模型结果复用于迁移检查。
- 选定 H 后，训练、验证、开发迁移检查和正式测试均使用该 H。适配预算保持原上限，不因时域增长自动增加团队步数。补训后不再次循环调整 H，也不依据正式测试更改 H；若最终仍饱和，利用下述耗时曲线及失败分解解释，必要的新标定另列后续实验。

**先测迁移，再决定训练**

四类学习资产分别为 Single、L5 排序器、MAPPO＋RouteAPF、PPO-C，均使用既有 17／29／43 三个种子。A3 与 A5 共用排序权重，不重复训练；七个无学习方法不训练。

三个种子仍各自保留独立模型实例、优化器、随机状态和验证记录；允许把同一方法的三个种子并行执行以缩短墙钟时间。并行调度不增加种子数量，不合并参数，也不改变正式评测中的三种子统计口径。

在开发集上评估全部冻结模型，预先固定以下触发规则：

- 在三档等权汇总的开发指标上，家族平均双捕率比参照低至少 **10 个百分点**，或平均原始效用低至少 **0.05**，触发该家族适配。
- 参照分别为 Single 对 GEOM、MAPPO＋RouteAPF 对 RouteAPF、PPO-C 对 A4；L5 的 A3 对 A2、A5 对 A4，任一触发即适配共享排序器。
- 按家族统一处理三个种子，不仅补训表现差的某个种子。

**适配预算**

- Single 与排序器优先热启动监督微调，共用最多 **20,000 个新规则公共状态**，其中 18,000 个训练、2,000 个监督验证；每家族每种子最多 **20 epoch**。
- 18,000 个训练状态来自训练地图，2,000 个监督验证状态来自独立验证地图，均由冻结控制器轨迹采集；按障碍档位及首捕前后分层抽样，某层不足则如实记录，全部失败轨迹保留。开发与测试地图不进入训练标签集。
- 教师统一使用新规则几何搜索、256 次完整模拟；排序器教师保留同池定义。每个状态每种标签最多查询一次，成本单列。
- MAPPO＋RouteAPF、PPO-C 从旧策略热启动，沿用各自已有更新算法和训练配方，每种子新增交互不超过 **50 万团队步**。
- 先短试训：监督 5 epoch、RL 约 10 万团队步，均计入上述上限。若三个种子均未取得至少 0.01 的验证效用提升，且监督路线也未降低至少 5% 的验证动作损失，则停止该家族继续投入。
- 检查点只按验证原始效用选择，平局取较早者，旧模型作为 step 0 候选。预算用尽仍低分则如实保留，不自动追加训练、换种子或从头扩训。

正式主表使用每个方法最终冻结的版本，注明哪些直接复用、哪些经过适配，以及实际新增训练成本。

## 4. 正式评测、统计与异常处理

学习方法包含 A3、A5、Single、MAPPO＋RouteAPF、PPO-C，共 5 族×3 个模型；另外 7 个方法各一个实例，共 **22 个方法实例**。

正式矩阵固定为：

**84 张地图 × 2 个隐藏世界 × 2 个配对评测随机流 × 22 个实例＝7,392 局。**

- 所有方法共享地图、初态和环境随机种子；随机流不依赖方法名称。
- MAPPO＋RouteAPF 沿用确定性部署；PPO-C 沿用随机部署。测试中不另选表现更好的执行模式。
- 主指标为双捕率；同时报告至少一捕率、目标捕获比例、首次捕获时间、首捕后完成情况、失败计剩余时域的完成成本及原始效用。
- 原始效用沿用“双捕指示 − 0.0025×实际执行步数”，步数按已发出的 1 秒决策动作计数，包含发生终局捕获的最后一个动作；另以子步时间报告首次、最终捕获及首捕后耗时。失败完成成本计至冻结的 H 步，同时报告完成成本/H；不使用训练塑形回报排名，也不混合不同 H 的效用作排名。
- ID、OOD 及三个障碍档位分开报告；整体先对各档位内 ID／OOD 各赋 50% 权重，再对三档等权平均。世界、随机流和模型种子先在地图内部平均。每个“档位×布局族”只有 4 张地图，细分结果应同时给出原始计数和不确定性，不据此做确定性排名。
- 按“障碍档位×布局族”分层，以整张地图为组作 bootstrap 10,000 次，保留世界、随机流与模型种子的配对结构。预设比较为 A3−A2、A3−A5、A2−A4、A3−A1、A2−GEOM、Single−GEOM、MAPPO＋RouteAPF−RouteAPF、PPO-C−A4，对主双捕率差给出同时 95% 区间。
- 完整记录观测更新至动作返回的 P50／P95／P99／最大耗时、超时率、停车率、零完整模拟率和实际模拟次数；构造、编译、历史吸收成本另列。
- 不增加其他预算档、延迟实验或冻结迁移正式副主表。

**方法优缺点与区分度分析**

除双捕率主表外，所有方法采用统一指标和分组，至少提供：

- **捕获随时间变化：**在同一冻结 H 的真实轨迹上画首捕、双捕累计比例曲线，并报告 0.25H、0.5H、0.75H、H 时的计数；失败保留在分母中，不能只比较成功局用时。这些是同一策略的进度曲线，不称为重新设定短截止时间后的独立测评。
- **首捕与二捕分解：**区分全程零捕、已有首捕但未双捕、成功双捕；同时报告首捕后完成率、首捕时剩余时间及后续耗时，避免把首捕过晚造成的失败全部归为协同不足。
- **可见与遮挡阶段：**记录目标可见比例、失去观测时长、重新发现时间，以及目标可见时仍未捕获的持续时间。未重新发现的轨迹按截尾记录，不能丢弃。对“搜不到”“看得到但追不上”“首捕后收尾慢”等描述提供轨迹证据，不仅凭胜率推断。
- **场景适应性：**比较三档障碍、ID／OOD 及布局族的配对差异；结合占据面积和通道结构描述弱点，报告计数与区间，不将少量个例概括为普遍结论。
- **效果与代价：**将双捕率、完成成本和动作耗时并列，结合已有 A2／A4、A3／A5、AG／IG 等对照判断排序、搜索和显式分配的贡献，不用单一总分掩盖取舍。
- **逐方法说明：**为 12 个方法各给出有证据的优势、失败模式、代价和结论范围；配对轨迹从共同任务中按预先固定的成功／失败类别和任务编号规则选取，不只挑某个方法获胜的例子。差异不确定或能力相近时明确报告。
