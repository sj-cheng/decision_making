# 大规模持续追击：5v5、16v16 重训与强基线评测

## 目标与任务设置

现有证据支持“小规模任务存在成功率天花板”，尚不能证明几何方法强仅由任务简单造成。本轮检验扩大规模、增加遮挡并引入学习型逃跑者后，各方法的能力差异；按用户选择，不增加2v2因果对照。

| 参数 | 5v5 | 16v16 |
|---|---|---|
| 地图 | 40×40 | 80×80 |
| 障碍数量 | 24／32／40 | 80／100／120 |
| 最长回合 | 160步 | 320步 |
| 双方速度 | 每轴位移上限均为1 | 每轴位移上限均为1 |

- 追击者始终存活、持续参与追击和观测；仅逃跑者被捕后退出。
- 每步移动后，距离小于1且无遮挡的逃跑者全部被捕。同一追击者可以同时捕获多个目标，重复覆盖只计一次。
- 追击者使用半径6内无遮挡观测、公共地图和队内共享历史；逃跑者读取全状态，明确作为偏向逃跑方的压力设定。
- 默认开局公布一次目标位置，供现有历史信念初始化，之后隐藏目标位置不得进入追击者决策。
- 保留连续位移动力学、同步决策和原有机器人间碰撞约定，不在本轮增加实车动力学。

## 环境与方法改造

新增独立的大规模实验链路，保留历史代码、权重和结果。任务配置统一携带人数、边界、时域、速度、感知及捕获规则；环境、训练和树内模拟读取同一配置。

- 移除固定两人、八障碍、20×20边界和80步时域限制。动作统一为`[追击者数量, 2]`，观察与信念按目标数量组织。
- 地图图结构按地图共享，目标信念分别更新；缓存公共路由，避免每个目标重复构造整张地图。保留地图引导运动模型作为共同近似，并报告它对学习型逃跑者的预测误差。
- 神经编码器支持可变数量的机器人、目标和障碍；联合策略输出完整团队动作。使用掩码与集合编码，分别训练两种规模，不加载旧2v2权重作为正式结果。
- AG改用多项式复杂度的矩形匹配；目标减少后，未匹配追击者继续支援最近目标，不再要求双方存活数量相等。
- 所有搜索方法共享捕获逻辑、信念接口、合法动作检查和预算记账；不枚举16人的动作笛卡尔积。

正式方法固定为：

| 系列 | 方法 |
|---|---|
| 几何与无学习参考 | IG、AG、随机提议MCTS、GEOM |
| 神经策略与搜索 | 网络直控、PRIOR、JOINT、同检查点JOINT关闭叶价值 |
| 几何融合 | 网络＋几何＋MCTS，固定25%随机、37.5%网络、37.5%几何提议 |
| 同池归因 | 均匀／几何／学习排序＋MCTS，以及几何／学习最高分直控 |

同池方法使用相同的候选生成规则，在固定公共状态检查中直接注入同一候选数组。通用MAPPO、RMAPPO、HASAC追击基线不纳入本轮。

## 重训与共同自博弈

- 两种规模分别训练，学习分支均使用17／29／43三个种子。共享检查点的消融不重复训练，也不把重复评测当作新训练种子。
- 追击者采用搜索监督初始化，再进行双边交替训练；排序网络使用共同公共状态与独立教师评价生成标签。逃跑者采用共享参数团队PPO训练。
- 各追击方法向共同追击者池提供快照；逃跑者面对各方法等权采样。每个交替阶段冻结对手池，所有追击分支使用同一逃跑者历史池，防止比较被专属弱对手影响。
- 最终增加61／73／89三个独立训练种子的逃跑者，针对冻结追击者池训练，仅使用训练地图；这些逃跑者不参与追击者选模。保留固定运动核与扩展RootPUCT作为参考。
- 先在独立工程地图标定吞吐、显存、教师成本，并在独立预实验训练、验证地图检查学习曲线，再冻结正式预算。无天数上限；正式运行前必须生成明确列出团队步数、教师查询数、训练轮数、更新次数和选模规则的预算清单。工程检查与预实验均不得使用封存测试地图。
- 同规模各学习分支使用相同在线交互上限，监督与教师成本另列。选模仅使用验证集；测试结果不触发追加训练。保存完整训练曲线，训练不足与算法失败分别解释。

### 预算清单的含义

先进行小规模试运行，确认实际计算成本和训练情况，再锁定正式实验的训练量与比较规则。

| 标定项目 | 含义 |
|---|---|
| 吞吐 | 每秒运行的环境步数、完成的搜索模拟数 |
| 显存 | 两种规模分别占用的显存，以及可并行训练的模型数 |
| 教师成本 | 用较强搜索生成动作或评分标签所需的计算量 |
| 学习曲线 | 模型随训练量增加是否进步，是否存在训练崩溃、奖励或数据问题 |

| 正式预算项目 | 含义 |
|---|---|
| 团队步数 | 整个团队共同推进一次环境算一步；16个追击者行动一次仍是一个团队步 |
| 教师查询数 | 调用搜索教师生成训练标签的次数，同时记录每次查询使用的模拟量 |
| 训练轮数 | 追击者与逃跑者交替训练、自博弈的轮数 |
| 更新次数 | 神经网络实际进行梯度更新的次数 |
| 选模规则 | 根据哪些验证指标选择检查点，不能看最终测试结果再挑模型 |

“无天数上限”不代表无限训练，而是不为了赶固定天数提前截断已确定的实验。正式训练量仍有明确上限；预算锁定后，不因神经网络输给几何方法而临时追加训练直到获胜。

## 正式评测与验收

- 每种规模建立280张训练图、56张验证图、112张封存测试图，覆盖七类既有布局族；测试各含56张ID和OOD图。增加障碍占地比例与通路检查，只按几何合法性、连通性及出生条件筛图。
- 每张测试图固定两个初态，所有方法配对使用相同地图、初态和环境随机种子。分别面对三名独立学习型逃跑者、固定运动核和RootPUCT，不以对手平均值掩盖单项退化。
- 搜索评测分为16／64次完整模拟和200／1000毫秒两套预算。时间预算覆盖观测更新至动作返回全过程；报告超时、零完整模拟、实际模拟量和最大耗时。直控报告实际耗时。
- 主要指标为目标捕获比例；同时报告全歼率、存活目标随时间曲线、捕获时间、失败计满时域的完成成本，以及完整决策耗时。分别报告两种规模和三个训练种子。
- 主要比较固定为融合对GEOM／AG／PRIOR、学习排序对同池几何排序、搜索对相应直控。按地图成组统计，给出同时置信区间；其余比较作描述分析。

工程验收必须覆盖：连续多次捕获、单步多杀、重复捕获去重、隔墙不捕获、追击者捕获后继续移动与观测、全部目标清除、超时终止、环境与树内转移一致、隐藏信息隔离、超过八障碍与16v16完整运行、保存恢复可复现。

GPU优先物理GPU3，容量不足再使用2／1，禁用GPU0；至少保留20个逻辑CPU。计时使用隔离物理核并校准并发。最终交付冻结协议、预算清单、全部模型、逐局轨迹、训练诊断、强基线比较和失败案例；如几何仍然最强，完整保留并据此更新判断。
