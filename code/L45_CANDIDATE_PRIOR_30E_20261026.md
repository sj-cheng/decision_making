# 几何候选先验：30轮独立有限试验

本轮用户明确授权训练一个候选评分网络。保留已存在的80轮试验及此前无网络搜索的失败记录。已有结果已知，因此本试验沿用原候选网络和PUCT机制，不据旧结果调整特征、奖励、温度、探索常数或深度；仅遵守本轮30轮上限并使用重新冻结的数据。不是完整NTE复现。

## 事前配置与预算

- 独立目录 `current/l45_candidate_prior_30e_20261026`；基准种子92020261026。
- 24张训练地图、6张验证地图、12张测试地图，三种拓扑long_wall/wall_corner/multi_route。完整地图及所有公共历史、A/B世界只属于一个分区。与机器已有公开历史包中的地图/历史散列均不重合。测试4实例/拓扑，H=4/6及速度1.1/1.3四组合；属于已知拓扑的新实例。
- 冻结D、原G、原RootPUCT3000真实对手、运动模型、8步FB模拟、首次重发现+捕获奖励、折扣0.95。动态策略仅接收公开观测，真值仅在环境、对手及事后评分使用。接管前历史由独立几何构造，后续真实闭环对手不读取追捕者本步选择。
- 仅候选共享64-64-ReLU评分MLP，64维公开特征；G硬标签+G分数softmax软标签；loss=软CE+0.5硬CE。Adam lr=.001、weight_decay=.0001，每批64状态。种子17/29/43各30轮，只按最小验证损失选模型，不挑测试最好的种子。
- 根先验为uniform/softmax(G评分)/softmax(网络logits)，后两者各混10%均匀概率；同一PUCT cpuct=1.5、深层均匀先验、同一候选/rollout/模型/深度/模拟上限4096，唯一区别为根先验。G与NET直接选候选另列。目标可见时五组均使用原几何追踪。
- 训练前先用临时随机网络验收接口、合法性、冻结D、固定次数重放、先验归一化和完整200ms时延；正式模型冻结后仅在验证地图复查。预热在训练/验证地图执行，编译作为一次性启动成本单独记录，不以测试预热。运行时地图/模型加载、历史回放计入首次200ms预算；D更新、候选、特征、推理、先验、搜索均计时。对手和环境耗时另报告联合控制周期。
- 最多30次G数据采集闭环、90个训练epoch、216局测试。CPU单线程；训练阶段最多900秒；完整流水线最多7200秒（含采集、预检、训练、测试及审计），达到上限原样保留已完成结果并报告未完成，不自动扩容。200ms是各追捕策略完整决策上限，实际超时均保留，不删除失败/慢局。G无需人为等待。

## 指标与停止条件（训练前冻结）

主指标为失败惩罚完成步数：合法捕获使用接管后步数；失败使用接管时剩余步数。辅指标为合法捕获率、目标重发现率、失败惩罚重发现步数、成功条件下重发现时间、动作合法性、逐项及完整耗时/P95/最大/超时与联合周期。完整模型/逐局结果按训练种子单列。

三项主要配对比较：学习先验搜索减手工先验搜索、学习先验搜索减对应种子NET直接控制、学习先验搜索减G；负值更好。每组先对A/B和三个种子等权平均，12个公共初始历史为独立统计单位，成组bootstrap10000次（seed92020261027），保留组内全部方法/世界/训练种子。三项完成成本差使用max-absolute-centered同时95%区间；均匀先验及捕获差为辅助普通区间，不将种子/帧当独立样本。按拓扑/种子结果为描述性分析，不据此选模型。

只有三项主要成本区间上界均<0、平均各至少改善1步、相对三基线的观测捕获率均不下降、每个种子的三项平均成本差均<0、全部工程审计通过且完整决策无200ms超时，才建议另行设计下一轮确认。捕获率不下降只是观察性护栏，不是非劣证明。任何一项未满足均结束本配置，不重调测试、不追加训练/模块/部署。区间跨0称证据不足；区间整体>0称本配置成本变差。训练损失或模仿一致率不证明任务/搜索价值。

本次冻结测试为对训练和调参独立的新实例评估；12组不能证明所有地图分布的结论。测试之后仅作描述性失败诊断，保存日志、数据清单、散列、模型和REPORT.md。
