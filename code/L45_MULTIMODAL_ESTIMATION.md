# 正常遮挡期间的多模态位置估计：冻结验证方案

2026-10-25；本阶段只定位/验证估计器，不调用MCTS决策，不训练网络，不改部署。

## 原因区分与固定对照

- 历史64粒子：原独立均匀位移预测、逐步剔除、随机重采样。
- 系统重采样64粒子：仅将随机重复抽样改为systematic；用于检查重采样影响，不把不同随机流的差异全归于单一因素。
- 确定性扩散格：有限格枚举相同每轴能力内的独立无方向运动，避免有限粒子样本灭绝。其离散化及边界条件与连续原粒子不完全相同，不能当作精确单因素因果效应。
- 多模态加权格：相同节点/合法边/历史约束，增加九种固定持续运动假设（静止、八个轴/对角方向），模式保持率0.9、运动核标准差0.35；不拟合真值。
- 可行集合均匀格：相同可行节点集合，平铺权重，仅作为“扩大支持就提高覆盖”的强诊断对照，不能把它当成校准概率。

共同格距0.5米，相对最后正测量锚定，保留精确场地边界；运动障碍和不可见判定保护余量1e-6米。所有保留点有符合**全部**空观测的合法祖先路径。测量重新出现时恢复到该位置。
加权格不把每种运动假设强行等概率；保留归一化位置×运动模式权重。导出仍为64个样本，分模式systematic抽样，并按模式质量/样本数赋权，不用虚增弱模式概率换覆盖。

## 数据与信息边界

开发：已查看的24组公共历史、两个隐藏世界、两个流；及原G的96条固定历史、3292个已记录观测帧。
独立确认：一次生成24组新历史（3拓扑×2遮挡档×2速度×2姿态），墙长分别从[6.15,6.65]、[8.15,8.65]按固定种子71020261025抽样。每组A/B世界、上下两条合法见证路径，共96条固定观测轨迹；不同墙长/历史长度，不只刚体变换。
确认仍来自三类已知拓扑和脚本运动，不宣称新拓扑或真实搜索对手的闭环泛化。

确认集在任何新估计结果产生前冻结并独立几何验收。代码、参数、方法选择在确认前锁定；本轮不扫参数、不按确认结果改模型或追加样本。若失败照实交付。
估计接口仅有公开地图、运动/感知规则和历史观测；没有世界标签、隐藏位置、真实速度或未来路径。真值只在输出固定后评分。

## 指标与通过条件

同时报告：64样本1米覆盖、完整加权分布1米质量、共同0.5米高斯核负对数密度、90%高密度区域的名义面积和覆盖、唯一粒子/祖先数量、有效运动模式数、代表性误差、路径/观测合法性、更新均值/P95及一次建图开销。
完整分布与导出64样本分开，不能把完整集合有真值写成64样本已覆盖。所有格方法的可行范围相同；主要看加权分布是否优于均匀集合的密度/集中程度。

确认通过需：无执行或证书失败；64样本接管覆盖≥75%、隐藏帧按历史等权覆盖≥70%；相对原粒子及均匀可行集合的历史配对核NLL差95%区间上界<0；90%名义面积不高于均匀集合；预热后的逐观测更新P95≤10ms（为未来50ms搜索预留预算），一次建图单列并如实计费。
bootstrap10000次，统计种子71120261025，按24组公共历史共同抽样各方法、A/B及上下路线，不能把帧当独立样本。
