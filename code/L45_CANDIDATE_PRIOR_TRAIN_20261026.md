# 强G监督候选先验：固定预算训练试验

用户在2026-10-26明确授权小规模神经训练，替代本轮沿用“无网络搜索先胜G才能训练”的研究限制。上一轮结论和冻结文件保持。只新增研究入口，不修改部署。

固定24训练/6验证/6测试整张地图，三种已知拓扑，测试每图A/B两世界。按公开几何构造与独立验收，在生成标签或效果结果之前冻结。地图及其所有公共历史、世界不能跨分区，且不复用历史实验地图。每图训练/验证仅采集强G在真实RootPUCT3000下world A轨迹及接管前公开历史的隐藏帧；不使用FB访问标签。完整公开历史驱动冻结D。

64维公开特征：自身位置/候选动作、剩余时间/速度、最近正观测及其时距、上一公开位移、至多两矩形地图及掩码、D带权样本相对候选端点的矩/距离/传感器覆盖和5x5概率直方图。没有隐藏坐标、未来轨迹、世界标签、候选序号或强G评分输入。共享候选MLP为64-64-ReLU标量打分；候选排列等变。硬标签G选择，软标签exp(G评分)，温度1；loss=软CE+0.5硬CE。Adam lr0.001、weight decay0.0001、每批64状态，种子17/29/43各80轮。检查点只按验证损失选取；不按测试选择种子或模型。

共九个执行臂、108局：G、均匀根先验PUCT-U、人工几何根先验PUCT-G、三种子NET直接控制、三种子学习根先验PUCT-L。所有搜索共用原FB信念模拟、8步、首次重发现+捕获奖励、0.95折扣和同一PUCT选择(cpuct1.5)；深层均为均匀先验；只改变根先验。人工先验为softmax(G评分)，学习先验为softmax(网络logits)，二者均混合10%均匀概率。强G与NET不人为等待，可见目标均用相同几何跟踪。

每局相同配对接管初态、D/搜索种子和对手种子。RootPUCT仅从共同步前状态选动作，无本步追捕动作泄漏。完整决策预算200ms，初始化(含模型载入/历史回放)从首次预算扣除；特征、推理、先验准备均计入预算。首次全部路径在验证地图预热。全部实际超时帧保留，任一超200ms阻止继续信号，不称严格硬实时。完整联合周期另保留日志。无价值网络、PPO或奖励调整。

主要终点失败惩罚完成成本：捕获用接管后步数、失败用接管时剩余步数。重发现成本同样保留失败。学习先验三个种子平均后，对G和PUCT-G的两项主要成本比较用6个公共历史成组配对bootstrap10000次；组内A/B和所有种子共同保留，用max-absolute-centered半径给两项同时95%区间；PUCT-U比较与捕获差普通区间仅辅助。种子不是新增独立样本，小样本捕获天花板不证明非劣。

探索继续门槛：种子平均学习先验成本相对G和PUCT-G均至少降低1步；相对二者观测捕获率不下降；三个种子各自相对二者成本差均<0；工程审计全部通过，实际完整决策(含首次初始化)无超200ms。满足也只交付独立确认设计，不自动扩大训练或修改部署。不满足则停止本配置。固定预算训练和108局评测执行完毕，不根据中途效果改参数/筛地图。

独立工程检查：强G评分一致，公开特征/动作输入隔离，候选与粒子排列，D逐位重放，三先验固定模拟数重放，模拟/真实动作与传感器/捕获检查；使用原v2审计检查完整公共历史与成对初态。实验源、既有源/报告、数据、模型、逐局缓存均保存散列；中断只从已提交完整局续跑。
