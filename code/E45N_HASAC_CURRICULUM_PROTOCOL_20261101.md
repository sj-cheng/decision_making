# E45-N：同一作者HASAC的可见到隐藏任务课程

动机：L中途数据显示随机初始化很少接触目标，J权重初始化接触与捕获明显更多。这提示从头隐藏任务的冷启动探索是优先候选，而不是只解释二捕信用。保留M的从头隐藏训练，另做既有HASAC的任务课程；不修改作者损失，不创造新算法，不把课程叫作完整复现某一论文。起始状态课程是已有RL研究方向，参考Florensa等Reverse Curriculum Generation（CoRL2017），本轮不复制其自动反向采样器，而复用本项目已经存在的真实可见历史起点。

信息约束、作者版本、模型、奖励、优化器、alpha、gamma/终点/退休/动作回放完全沿用M。两独立actor、双Q及作者顺序更新，无教师标签、无显式指派或角色。阶段变化只作用于训练环境；可见课程目标必须真的被原传感器报告，不向actor拼接隐藏真值。输入尺寸不变。

从L/M同三组训练历史取已有J课程文件，AB/BA共6情形。依次：

|阶段|环境|新增转移上限|转段条件|
|---|---|---:|---|
|static_visible|原历史首个真实可见状态，2v2静止目标|20000|阶段终点确定性至少5/6双捕|
|moving_visible|同可见起点，真实固定D动态目标|30000|阶段终点确定性至少5/6双捕|
|hidden_root|原始隐藏历史接管、RootPUCT3000|100000|报告全部检查点与终点，不因中途分数加预算|

完整12局批次可轻微越过各阶段上限。17/29两种子随机初始化，最大150k/种子（课程50k＋隐藏100k），总最多300k；M是隐藏100k/种子，必须分别披露课程额外成本，不能声称总样本预算相同。前两阶段未过门槛停止该种子、保存gate_failed，属于学习失败，不是软件异常；原种子保留，不换成功种子。不会跳过失败阶段偷偷声称已经训练隐藏主任务。

若N优于M，首先只支持“课程＋额外课程预算”的组合效果；若要单独归因于课程，需要另做等总步数延长对照。本轮目标先建立可信学习能力，不预写课程独立因果收益。

目标动力学变化时清空经验回放（并更换独立回放RNG），避免把静止、固定D和Root的旧MDP转移混入当前Q目标。保留actor/critic/目标网络/优化器权重与状态，不重新初始化。均匀动作预热仅最初2000步，计入静止阶段。每非预热新转移一次作者梯度更新，batch256、容量50k，其他参数同M。

每阶段开始、每约10k阶段步和阶段终点：评估当前阶段确定性6局及随机12局，另评估原隐藏Root训练情形的确定性6局（隐藏阶段与自身确定性评估相同，避免重复）。隐藏探针不选模、不决定可见阶段门槛；无验证或测试历史。所有分数按原始双捕/首捕/效用，固定checkpoint全部保留。训练内过线仍不能当广分布泛化或强baseline完成。

检查点按阶段分目录，保留等全局步数的转段前后独立快照；保存全部M模型/优化器/回放/RNG及带阶段标记的评估历史。源码、父M源码/上游、所有课程与隐藏历史SHA冻结，不改M/L注册预算与结果。恢复从最后完整检查点继续，阶段门槛重新判断必须幂等。

smoke单独目录仅种子17，一个训练历史AB/BA，每阶段完整2局、2次作者GPU更新，覆盖三种真实环境与两次清空回放。为了验证代码路径，smoke显式绕过学习门槛，绝不能作能力通过证据。须验证三阶段结果均有、6次更新、真传感器输入、回放重新起步，软件无失败，才排队正式实验。

正式任务在tmux独立会话等待M正常结束后自动启动，GPU1、每种子8采样物理核＋1更新核；不停止其他任务。协调器墙钟含等待上限12小时。若父实验软件失败则暂停自动扩展并留下失败状态；不静默重启。窗口直接显示LIVE.txt与日志。
