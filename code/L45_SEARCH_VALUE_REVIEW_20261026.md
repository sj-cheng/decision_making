# 搜索价值验证：独立设计审查草稿

2026-10-26，Asia/Shanghai。本文件是结果生成前的审查建议，不是已执行实验或最终冻结协议；最终样本量、预算和判定以主执行器冻结协议为准。只读审查 D、旧闭环和最新 rollout 报告，没有启动新效果实验。

## 最小实验矩阵

建议保留同一 D、同一 G、同一公共几何候选、奖励和物理规划时长，比较 G、OL-200、FB-200、OL-H、FB-H。OL 与 FB 在同一预算中只改变未来模拟观测是否参与树内信念/策略；H 是明确单列、不声称实时的高预算参考。两种目标条件分别报告：公开运动生成模型匹配诊断、原 RootPUCT 真实对手。不能把更换对手带来的总体胜率差解释为观测反馈的因果效应。

同样 200ms 是实际入口到返回上限，计入地图/历史初始化的首次扣费、估计、候选、树内滤波、树/缓存准备、搜索、最终动作检查；G 不人为等待。固定模拟数重放独立于真实时限效果统计。高预算仍需报告实际时延，不称可部署。保持物理规划时长相同，不能把 FB 增加深度的效果归为观测反馈。

## 工程门槛

1. 根公共历史相同时 D 位置、权重、模式与旧版本逐位相同，树内副本不得修改真实估计器或真实估计 RNG。
2. 模拟世界从公共信念抽样。双方动作从共同步前状态独立生成；模拟追捕动作只接收模拟观测历史或信念，不接收目标采样的隐藏坐标/模式。
3. 模拟正观测只能由同一公开传感器产生；空观测必须作为约束进入信念。不得用目标真实分支标签、是否即将捕获、未来真值决定本步动作。
4. 改变不可见目标但保持同一公共模拟历史，当前动作分布不变；一旦模拟观测真正不同，后续动作允许不同。正观测后的直接几何追踪是合法反馈，不是隐藏真值泄漏。
5. 树节点应按可用动作—观测历史/信念区分，不能按隐藏世界身份分支。连续正观测的合并/渐进扩展规则预登记；不能从单个隐藏样本构造虚假的确定信念。
6. 每次模拟更新后的概率有限、非负、归一、观测似然约束正确。空支持显式失败，不能将非法动作或滤波失败作为普通零收益终止回传。
7. 缓存键必须包含影响信念的公共模拟历史，不能只按模拟自身位置缓存动态信念动作。固定数重放、禁缓存对照和独立几何/传感器审计通过后才运行开发完整对局。

## 模型匹配的特殊陷阱

D 的公开转向概率以最后正观测位置 `last` 为意图目标锚。每次正观测会清图、将位置测量置为 64 个等权样本；下一隐藏帧以新的 last 重建图并初始化模式。因此：

- 单纯让真实目标始终运行接管时的固定图 `target_step`，只能称接管段模型匹配；首次重发现后 D 可能换锚，未来失配不能隐去。
- 原 A/B 脚本 handoff 连续坐标通常不在 D 的格点上。不能偷偷吸附真值到最近格点并沿用原初态标签。若需要精确生成匹配诊断，应从共同公共 posterior/条件模式独立抽取初态，对全部方法使用同一个抽样；明确区别于 RootPUCT 原初态。
- 可选的严格匹配生成规则是目标随公开正观测事件更新锚/重置模式。若采用，必须预登记并说明目标运动依赖“被看见”事件；方法改变观测会改变该对手的未来策略。这是一个特定合成对手，不代表原 RootPUCT。
- 替代办法是将匹配诊断终点限定到首次重发现，闭环捕获仍以 RootPUCT 为真实任务验收。不能把这两个终点混为一项。

## 统计与停止建议

最新确认 G=47/48，捕获差的改善空间仅 2.08pp。新协议可以预登记失败惩罚完成成本为主要收益终点、捕获为非劣约束；这不更改旧实验“未通过”的结论。若继续把捕获改善作为唯一通过门槛，应明确小规模筛选可能因天花板和精度不足停止，并非证明搜索无效。

成本成功局取接管后完成步数，失败取接管时剩余步数；重发现时间同样保留失败，不能只看成功子样本。捕获、重发现、成本、完整时延、合法性和所有失败逐项报告。

同一公共历史内保留 A/B 或生成世界、所有方法及目标条件；以公共历史为独立组做配对 bootstrap，不把帧/模拟次数当样本量。主比较建议集中于 FB-H 对 G（高预算是否有值得压缩的搜索价值）和 FB-H 对 OL-H（是否确为观测反馈增量）；200ms 结果回答现实预算下能否实现，不能和高预算合并推断。若多条件/多比较都用于通过决定，对这整个家族预登记校正。

捕获接近全成功时，成组 bootstrap 的全零差会退化为 [0,0]，不应凭此声称任意窄的捕获非劣。可另计算“任一新法失败而基线成功”的坏公共历史概率的单侧 Clopper–Pearson 上界，作为保守捕获退化界；零坏历史时，24 组的单侧95%上界仍约11.73%，若要压到5%至少约59个独立历史，多个比较同时保证还需更多。小样本只称筛选，不能声称已证明等效。

停止规则须区分三种结论：工程不通过而停止；高预算在登记模型/时长/场景上没有确认可利用价值而停止；高预算有价值但200ms未达到，留下“搜索效率待解决”的具体问题。模型匹配成功但 RootPUCT 不成功，应报告泛化/模型失配限制，不能立即进入教师生成和神经训练。

独立确认银行必须在开发结果前冻结，按公开几何验收，不能按 G 或任一算法输赢挑选。开发后仅修工程问题必须新版本登记，确认一旦消费就不能追调；已用确认一律变为开发证据。不能挑出多通路的正例替代总体成组结论。

## 本轮应保留的结论边界

通过只说明某个明确模型、观测策略类、物理时长和预算中的局部搜索价值，不是任意 MCTS/NTE 最优性证明。失败也只停止这个已登记版本。尚未确认真实闭环优势、同信息教师可靠性和预算压缩价值前，不生成训练标签、不训练网络、不改部署。
