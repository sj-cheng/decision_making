文献检索与下一步研究方向（2026-10-24）

本记录对应用户关于“末尾加入 PPO 未形成足够收益，还能研究什么”的问题。本轮完成文献和代码核对；下文实验均为建议，没有启动新的训练、正式评测或更换推荐模型。

**判断：调整研究主线，保留已经验证的能力。**

PPO 可以作为实现工具，但“在 NTE 后加入 PPO”本身不足以说明算法创新。现有实验也没有独立确认它相对同价值配置原模型的额外收益。继续为了保留这个模块而调整训练，不是目前证据支持的优先方向。建议把研究问题转为：连续追逃中，如何让搜索对候选动作的评价更接近实际闭环部署结果。

**实验依据及其边界。**

- [价值配置独立确认](../current/l45_value_off_confirm_20261023/REPORT.md)：原 l45 为 74.67%，只关闭追捕旧价值为 85.00%，O 为 87.33%。关闭旧价值的 +10.33 点经过确认；PPO 相对同配置 l45 的 +2.33 点未独立确认。不能把 +12.67 点全部记到 PPO 名下，也不能据此断言 PPO 在任何训练方案下都无效。
- [AQ 新场景验证](../current/l45_aq_once_20261024/CONCLUSION.md)：四障碍 O 为 86.00%，AQ 为 86.67%，L 为 84.00%。AQ 对两个参考未通过预定门槛。Search Only 子项挽回 14、丢失 11；O 的 38 次失败中 33 次发生在首捕之后。它说明第二捕和动作选择值得研究，没有证明这些胜负可由部署特征可靠预测。
- [硬 KL 搜索监督](../current/l45_guarded_supervision_20261023/REPORT.md)未通过采用门槛；[阶段接管](../current/l45_phase_handoff_20261023/REPORT.md)也没有证明把 O 首捕后换成 S 有净收益。下一轮不宜继续围绕相同检查点切换或机械改选扩大试验。

**发现一项必须先查清的搜索建模差异。**

真实对局在 [TeamSolver.policy](solvers/baselines.py) 中让双方根据同一个状态决策，再合并动作推进环境。当前 [puct_v1.hpp](cpp/solvers/puct_v1.hpp) 的 `tree_turn`、`keep_turn_action`、`expand_node` 和 `default_policy` 则轮换双方，将非行动方动作归零，每条边推进完整 `m_timestep`。在本实验关闭 MINCO 的环境中，这相当于树内一方移动时另一方停留；连续两条边也消耗两个时间步。

构造性检查已经得到反例：无障碍、首捕后剩余一追一逃、捕获半径 1，初距约 1.27675；双方沿相同方向各移动约 0.55351。真实联合推进后距离不变，不捕获；只推进追捕方则判定捕获。状态合法、动作在范围内。该检查不是新的效果实验，也没有测出此差异在实际搜索中出现的频率或对胜率的净影响。

原 NTE 论文同时有“按轮次选择节点”的文字说明，以及 Algorithm 2 对所有机器人采样联合动作后一次推进的伪代码。因此不能把当前代码的单方归零规则直接归为原论文的方法，更不能宣称找到了原论文的错误。先区分原论文、原仓库版本和目前经过修改的实现。恢复一致性属于工程修正；它本身不能充当论文核心创新。

**推荐主线：用实际部署结果学习候选动作的相对价值。**

工作问题可以表述为：“在固定搜索预算下，能否从部署时可见的信息识别比原搜索动作更好的连续联合动作，尤其减少第二捕阶段的超时？”

固定原 actor，用现有搜索产生候选。对同一状态和搜索随机流，分别执行原动作 A0 与候选 a；此后双方按照冻结部署策略在各自的新状态上重新决策，保留原剩余时间。标签为成对差值：

`Δ(s,a) = E[合法双捕 | 首步 a，之后冻结部署] − E[合法双捕 | 首步 A0，之后冻结部署]`。

首版只在首次合法捕获后的下一次决策调用，且只比较 A0 与 AQ，使问题直接对应已观测到的挽回/丢失。学习器输入限于该决策时真实可得的观测、剩余时间、活动标记、候选动作及搜索统计；不能输入后续轨迹、真实对手当前动作、未来搜索结果。阶段信息是否有效单独消融，不能仅通过增加输入维度声称贡献。

预测优势不足或样本覆盖不足时保留 A0。阈值只在拟合/开发分区确定，独立确认前锁定；未校准的不确定性不能称为统计保证。首次使用单次替换，是为了使续跑标签与部署策略对应；若以后改成每步反复替换，必须重新定义续跑策略和标签，不能沿用单次干预的效果解释。

这与再训练 actor 有实质区别：保留已经学到的候选生成能力，研究候选评价和采用机制。与简单 SAVE 的区别应落实为同状态成对部署结果、有限剩余时间下的第二捕目标，以及保留基线的采用规则；这些细节是否足以形成研究贡献，仍须强基线、消融、机制解释和进一步查新证明。

环境奖励可以保持不变，但用合法双捕概率选择动作属于新增决策准则，必须明确报告。不能称作完全没有改变优化目标，也不能把额外离线续跑的计算量隐藏为免费数据。

**实施顺序与停止条件建议。**

1. 先做有界的一致性诊断。冻结现有源码与模型，在已有完整首捕状态上比较同步联合推进和单方推进的捕获、碰撞、时间差异；补充少量构造边界状态。现有历史数据在此明确作为探索材料。分开报告语义差异和闭环效果，不用差异存在代替性能证据。
2. 独立实现同时行动的搜索基线：双方动作根据同一决策前状态产生，一次联合推进。若使用顺序化数据结构，后选择的一方不能获得本步对手动作或已经推进的状态。候选交互的选择可借鉴 SM-MCTS；不能简单把“取消动作掩码”当成完成整个同时行动求解器。此阶段不训练，检查它是否改变候选排序及真实收尾结果。
3. 利用既有配对分支做可学习性探索。按原始物理场景分组，所有候选、对手和随机流放在同一分区。比较恒选 A0、恒选 AQ、低复杂度条件规则与学习器；特别报告挽回和丢失，而非只报标签准确率。现有约百个场景不足以支持大网络和泛化结论；如组外预测没有价值，停止这一学习方案。
4. 可学习性通过后，才登记新的数据预算、模型和唯一验证候选。以 L（原 l45、关闭旧价值）为主要起点采集与其部署一致的标签；已有 O 分支只能作探索或另行登记的迁移资料。这样可以证明新机制是否独立于 PPO。O 继续作为强参考，不能把在 O 上训练或叠加的方案称作未经 PPO。
5. 做 2×2 消融：L；L+同步搜索；L+新评价器；L+同步搜索+新评价器。每种评价器的标签对应自己的续跑搜索配置，训练数据规模和算力匹配。另加 O 与相关搜索/价值学习基线；若主张改进原 NTE，还需在同环境同信息条件下补齐忠实实现对照。
6. 新场景整局验证通过后，才独立确认和逃逸回归。沿用对两个参考的成功率、非法率、各对手和无障碍限制，锁定唯一候选；不根据确认结果重新选择方法。方法论文若声称训练稳定，还需要独立训练种子，不能由单个固定模型结果代替。

公平预算至少报告搜索模拟次数、环境转移调用数、神经网络调用数、离线标签代价及单进程实测耗时。同步与交替树每层代表的物理时间不同，不能只比较相同“深度 100”；必须对齐实际剩余时间，并分别给出相同模拟预算和相同耗时下的结果。树内调用真实强对手求解器会引入额外预算和先验，不能不计成本地使用。

**其他方向的优先级。**

对手建模是第二研究方向：如果一致性修正后，错误主要来自对 Search Only 行为的预测，可研究使用历史观测的对手条件搜索；是否提高对未见对手的能力比识别三个固定对手编号更有意义。可达性价值是第三方向：如果剩余时间与障碍几何主导失败，再考虑一追一逃的有限时域可达性估计。两者当前都缺少足够的本地瓶颈证据，不建议与主线同时加入。

暂不继续强对手 PPO 加量、放松 KL、固定换模型、恒选另一个根动作或重新添加完成奖励。保留 O 作为部署推荐；把已有失败结果用于收窄问题，而不是把它们包装成对所有强化学习或神经搜索方法的否定。
