# E45-O：GEOM_SEARCH 示范回放辅助 HASAC 小规模对照

用户于2026-11-01授权实施方案一。本轮只改变回放数据来源与采样分布，不加BC/KL损失，不改作者HASAC损失、网络、顺序更新、奖励、输入或部署接口。称“示范辅助HASAC”，不冒称原算法默认配置。保留并核验M/N及上游冻结文件。本轮不是最终论文强基线或泛化测试。

## 数据与信息

沿用L/M的三个地图族、AB/BA共六个固定隐藏训练情形、RootPUCT3000和固定环境种子。直接复用L保存的全部六条GEOM_SEARCH正向控制完整轨迹，按训练历史身份选取，不按成功与否筛选。它们恰好全部双捕，此事实已被开发人员查看；没有新验证/测试数据。逐帧重建同一公共历史、J-01过滤及845维actor特征，并与原轨迹信念签名核对。训练critic末4维真值单独披露，actor不读真值。

教师来自200ms无分配联合几何搜索，有额外规划计算，不称轻量最近目标控制器。教师动作采用明确的“合法物理动作/速度”的规范化意图，转float32后用共同安全映射重放，物理误差须<=2e-6；不声称恢复了教师原始未投影候选。归一化动作、额外缩幅成本、势函数和奖励由实际重建计算。完整保留首捕后的轨迹、退场mask与团队末态；仅真正有限时域终点/双捕设done，下一态同局对齐，终点吸收零态。

冻结原轨迹SHA、地图SHA、重建episode数组SHA及合并数据SHA；登记历史教师环境转移、模拟转移与在线动作耗时。历史数据无需重新采集；不把复用误记为新教师采样。六条轨迹很小、覆盖有限，后续失败不能概括为所有示范方法无效。

## 对照与预算

baseline/guided各种子17、29，四条全新随机初始化训练。baseline使用原Replay；guided将教师数据放在不可覆盖的独立区域，每batch256固定64条教师、192条在线，整体打乱。在线仍按随机actor采集完整对局，不逐步切换教师；教师不参与在线动作执行。教师采样和在线采样共用可恢复RNG。教师轨迹跨种子复用，各模型的数据访问成本和全实验实际采集成本分别说明。

每模型名义总预算50000团队转移。baseline全为在线；guided的在线上限50000减去示范转移数。完整12局批次可略超，实际值逐批记录。原2000步在线均匀意图预热保留；学习开始后累计更新目标为max(0,在线步+该臂示范步-2000)，UTD1，batch256，在线容量50000，教师保留比例固定25%不退火。原学习率5e-4、alpha .001、gamma1、1-step、奖励和退休规则不变。预热来源构成仍有差别，不宣称除数据以外的访问分布完全相同。

原M/N作为历史记录保留，不拼作本轮新种子。每模型记录真实在线步、示范步、总计费步和更新数。全局墙钟上限12小时，四模型各4个空闲物理采样核和1个更新核，共用空闲GPU1，不终止其他任务。

## 评估与继续条件

初始、每约10000在线步及终点，分别确定性6局、随机固定动作种子12局。部署完全复用原M的纯Actor控制器，没有教师、搜索或Q在线调用。所有固定检查点完整报告，无最佳模型替换终点、无失败种子替换。由于guided含历史示范步，总预算和检查点在线坐标同时披露，末次预算允许整批超出。

诊断目标：每种子最后连续三个固定检查点均至少5/6确定性双捕；同时报告随机执行、首捕和原始效用，不用塑形回报代替任务成绩。该目标只用于决定是否值得扩到更多训练历史与新ID/OOD，不是统计显著性或泛化证明。若仅示范数据好、纯Actor仍失败，保留失败并检查价值传播/表示/退化；不自动追加BC损失或无限预算。
