# 冻结D到局部搜索：接口与50ms门槛

2026-10-26。D保持原冻结快照和全部参数，不优化估计器、不改部署、不训练网络。
本阶段先验收接口；本文件在结果生成前登记。已看过的D确认历史只作工程开发。

## 输入与概率

控制器仅接收公开地图、自身限速、随机种子以及Observation，不接收环境状态、目标身份、未来观测或路线。
G/T/T+Geo分别加载同一研究快照。估计随机流与搜索随机流隔离；共同历史下64位置、权重和估计器RNG必须逐位一致。
根节点先按64样本的重要性权重采样，再按该网格点D后验的条件模式概率抽取潜在意图。
条件模式是公开历史后验的辅助量，三组访问权限相同；不重新使用全网格的位置边际替换64样本。
重复位置的权重相加，不等权抽取，也不均匀提升弱分支。

模拟下一模式的概率为0.9持久化+0.1均匀重置，再按冻结图上对应模式的归一化边概率移动。
不接入旧R2的独立均匀运动/逃离追踪者的提议模型。传感器用真实公开地图和6m半径。
模拟传播核与D滤波核在每个合法边上的解析概率一致；D的数值遮挡保护与精确传感器的边界分歧单独核算。
64样本后验近似与全后验的差异单独报告，不能将其当作运动核不一致，也不宣称真实对手服从该先验。

## 工程搜索探针（不是效果对照）

带权根采样的开环UCT，8步规划深度（不足8步时取剩余时长），最大1000次模拟。
树节点索引动作历史，节点选择和rollout动作不得读取模拟的隐藏目标位置/模式。
根动作T为9个轴限速罗盘/停止；T+Geo仅额外加入公开地图顶点、带权区域代表点的首段几何动作。
更深层两组均使用相同9个动作，rollout使用共同G首段方向，非法则停止。
模拟奖励为首次重发现+1、合法捕获+1，折扣0.95；规划到叶节点记为预定规划截断，不能混同环境结束或故障。
本探针不将采样目标当成观测，不根据隐藏位置生成追踪动作。它没有观测分支，不能宣称已完成完整belief-tree验证。
G保留带权几何强基线：对所有区域代表点、公开可绕行顶点及基础动作，比较期望几何路程和可视概率。
实际效果研究开始前还须冻结对手、搜索语义和新的受控/确认场景；不得由本探针奖励推断搜索收益。

## 计时与验收（先执行，后读结果）

串行计时，数值线程数1；JIT首次编译另列，不混进暖机后的时延。
静态地图构造、历史初始化、每步估计更新（含按需建图）、候选生成、树准备/搜索和最终合法检查分别记录。
决策总时延从入口开始至最终合法动作返回；50ms预算内预留2ms安全余量，估计/候选已超时不得再启动搜索。
任何预算失败不通过删除建图帧、排除首次遮挡或藏起历史初始化来修饰。

共同历史：使用前阶段24组公共历史，每组轮换执行三方法；额外重放可见→不可见重建事件并计时。
工程验收：权重非负归一化；64导出一致；根采样分布误差不超过预先登记的6倍二项标准差+2/N；
解析一步负观测条件分布与D propagate最大误差<1e-12；所有使用图边和模拟路径独立几何检查零非法；
固定模拟数重放逐位一致；公开输入相同、外部虚设隐藏世界变化时动作/根统计逐位一致。
预算验收：每组方法普通隐藏帧、首次遮挡重建帧、历史初始化加首次决策分别P95≤50ms，并报告所有>50ms和最大值。
这是P95可行性门槛，不是硬实时保证；将失败率一并呈现。

任一前置接口/预算门槛失败，停止在工程报告，不运行G/T/T+Geo捕获收益比较，不消耗独立效果确认集。
通过后另行冻结同对手、同信息、同50ms总预算的受控消融及独立新场景，按公共场景聚类比较重发现、合法捕获、失败惩罚完成步数和时延。
