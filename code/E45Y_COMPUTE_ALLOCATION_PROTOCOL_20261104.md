# E45-Y：决策分歧与计算预算分配的可行性诊断

## 顺序与问题

用户授权按既定方法创新候选逐步检验。X 的首捕事件小诊断已完整完成，未建立事件停止的独立收益，按停止条件收住该实现。本轮进入候选二的第一阶段：不同公共状态上额外搜索的收益是否不同，廉价的动作排序分歧能否识别有益的计算投入。

这是状态级/批次级可行性诊断，不是完整在线调度器，也不是整局闭环成功率实验。先不做新策略训练，不因低分调整阈值、换种子或增加网络。

## 固定输入与参考

沿用 X 的冻结 Single17、6个根候选、47个公共根（24 train/23 development）、6训练/6开发地图。它们已经用于 X 的探索，不能称全新确认集。沿用 X 每个开发根/候选的8个反事实世界：根动作干预一次，之后固定 Single 续跑。参考不是最优 Q。

新规划随机流与这些参考世界独立。每根4个搜索重复，统计单位仍是地图。不得读取 W 封存测试结果或地图内容。

## 搜索前缀

每个公共根构建同一棵原评分机制的8步上限树，在约200ms计算预算下连续扩展。保存每次完整模拟后的动作/访问数/耗时，因而可从同一次搜索中查询50ms、任意中间预算和200ms的可用动作。当前观测更新、特征、模型准备和搜索包含在前缀时钟；前缀历史恢复单独计费。固定根候选来自 X 的离线公共构建，不能把本诊断包装成无前处理的完整部署接口。

增量分歧判断单独测时。baseline前缀时钟扣除这次专用判断的时间；自适应分配查询时，再从其50/200ms预算中扣除此开销，避免免费门控。所得证据是前缀重放，尚未核验真正在线中断/恢复的端到端时延。

## 公共分歧分数

从当前公共后验独立抽16个模型世界，各目标按D核预测一步。对全部六候选使用同一组世界，计算一阶几何任务代理：一步原始奖励加退休后剩余目标至活跃车的几何距离势。内部采样的目标点只作公共后验上的积分，没有使用真实环境隐藏状态，也不直接生成针对某个真目标的执行动作。

对这16行、6列的代理评分进行128次固定种子的行bootstrap。primary分数是bootstrap下更换最优动作可能减少的平均代理损失；同时保存排序变化比例和世界逐一最佳动作的分歧。前者只反映这个代理估计的采样不稳定性，后者还包含不可约的状态不确定性。均不宣称是精确的计算价值、真实Q置信度或性能保证。

熵对照先合并重复空间粒子再计算；已知目标的64个重复点应给出0空间熵。probe使用独立随机数，不推进树的任何随机流。

## 预算与对照

只用 train 分数为每种对手固定2/3分位阈值，严格大于阈值的开发状态获200ms，其余50ms。每次重复的开发批次出现K个高预算状态时，所有对照匹配相同的总名义分配预算：uniform每根分配该批次平均预算；random均匀随机选K个；entropy按空间熵选K个；stratum-random还匹配handover/临近类别内的K。随机对照作1000次廉价分配平均，不新增搜索或环境采样。

primary阈值本身只依赖训练分数，当前状态的门控不读取未来状态或参考效能。entropy-topK和exact-K随机对照用于离线公平比较，不宣称是已经完成的流式在线策略。所有策略名义单状态上限200ms；实际在线效果还需后续完整闭环检验。

另报参考标签分配：在相同K下按参考中的高/低预算收益排序，作为乐观诊断，不作可部署方法或理论上界。为减少同一有限标签选配与计分的偏差，同时做8世界的偶/奇4+4交叉分配与评估。该参考分配器也不可部署。

## 并行与验收

所有新CUDA进程仅物理GPU3，`CUDA_VISIBLE_DEVICES=3`。这是计时实验，使用独立物理CPU48–51：先串行/4路比较模拟吞吐及CPU/wall，4路满足>=.8吞吐与>=.8 CPU/wall则使用4路，否则退回1路。校准不读取效能。原 W 继续执行。

工程验收检查重复粒子熵、代理分歧、probe不消耗树RNG、前缀查询不越过预算、判断开销扣除、参考标签不影响主门控，以及所有对照总名义预算一致。保存源/输入哈希、模型冻结、失败任务和独立物理审计。

## 停止和解释

只做本轮限定的可行性检验。若额外计算无稳定收益，或分歧门控不胜等预算uniform/random/entropy，就不把这版规则升级为方法。若仅乐观标签分配有效，只说明存在分配空间，并未找到可用门控。若primary在两对手均有一致正信号，再单独设计新地图的完整在线预算调度与闭环确认。

地图组bootstrap区间只作探索性描述，不校正多个对照，不代表训练种子总体。纯阈值门控/自适应细化本身已有文献，本轮效果也不自动证明新颖性。
