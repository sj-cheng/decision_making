## 方法与信息

MAPPO和IPPO各17/29/43三个独立训练种子，从随机初始化训练共享二维actor；不继承l45权重，不使用在线专家分配、AG动作或搜索教师。actor输入与当前Single相同的公开地图、团队状态、64带权D目标样本及最多16帧公共历史，再加自身agent特征和ID。信息共享前提与当前方法一致，不称无通信个体局部部署。

两方法actor结构相同、训练代码相同。IPPO每agent critic仅访问公共输入；MAPPO的critic训练期间另外访问四个归一化目标真坐标，属于明确的CTDE特权信息；部署只导出actor，部署输入绝无真值。critic输出/训练都保留团队回报的退休后续行信用，actor loss只在退休前计费。

信念为F的Recorded/Refined D包装，G另覆盖冻结Estimator在内部单观测传播就抛空支持的入口：仍在公开历史中找最后正观测，用0.25间距重放全部后续团队负观测。若仍无支持，保留现场并记录无效，不读取隐藏目标去恢复。此修订同时用于MAPPO/IPPO和所有新确认参考方法，正常路径不改。固定D核环境对手仍保留原初始化和转移定义，不把改信念包装解释为全程模型匹配。

所有方法共享target-free合法动作映射：对归一化位移tanh结果做有上限的逐次减半，无法接受则停止。已有搜索合法动作通过此映射时不改变决策规则。PPO记录原始高斯latent样本和log-prob，安全映射是确定的环境映射，不把拒绝后的条件样本当无条件密度。统计所有缩短和停止，安全规则不提供追踪方向或分工。
