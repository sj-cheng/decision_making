# G/T/T+Geo重复闭环与搜索失效归因

2026-10-26。用户要求“再做一遍实验，为什么不如G”。D不改、无训练、无部署修改。
原结果及源码保持不变。全部本轮结果在独立目录保存。

## A：原样重复

原确认24公共历史×A/B×三方法144局，使用相同种子、200ms预算、1000模拟上限、8步开环树和原3000模拟对手。
真实对手每步重新搜索，不从旧轨迹复用未来动作。复现为已见场景的重复，不是144个新增独立样本。
逐帧对比公开观测、动作、真实联合轨迹、64样本/权重、RNG、根访问/回报、模拟轨迹散列；时间允许不同。
重新计时并分组统计；任何差异/超时都保留，不调参数强求一致。

## B：共同历史上的离线2×2诊断

从原确认银行每family×H×speed取manifest第一个变体，即12个公共历史；A世界各取G原轨迹接管帧与隐藏中位帧，固定24个根。
根信息仅来自原公开历史及到根为止G收到的观测。相同D种子，G/T/T+Geo分别在同一根运行1000次，得到待比较的根动作。
三动作各接受同一批1024个D带权根世界及潜在模式、24步目标运动路径。控制器/候选不接收原隐藏真值。
2×2因素：规划评估视野8/24步；后续自身动作重复根G位移/每步用同一个根64带权信念重新计算G几何动作。
后者只隔离几何重规划，使用根信念快照，不吸收未来负/正观测、不宣称模拟中运行完整D滤波。
两种自身路径只依赖公开根信念和自身位置，因此可在采样目标路径前独立生成；非法动作共同回退停止且计数。
奖励不改：首次可见+1、捕获+1，折扣0.95，捕获终止；8步与24步复用同一前缀。目标转移仍严格使用D。
逐根报告模型中的重发现率/捕获率/回报、G动作的排名、搜索动作与G的回报差和几何剩余路程。
只做成对机制对照，不按结果选新控制器，不将模型内评分提升叫作实际捕获提升。

辅助核查：同根T是否包含G动作、T+Geo是否包含G动作；重复位移产生的非法回退率；隐藏根回报是否为空；根动作对静态几何进展的取舍。
对实际对手模型失配，本轮只报告模型与真实对手的策略差异和预测失败证据，不更换对手、不用真值补先验，不据此声称已经隔离其唯一因果影响。

## 解释边界

144局原样复现不能扩充有效样本量，仍24公共历史成组。诊断24根也来自已见数据，只是开发归因。
离线评估回报变化能定位动作排名依赖何种假设，不能代替真实闭环消融或独立新场景确认。
若只发现代码机制与行为证据而不能唯一归因，明确列出已证明和仍未证明部分；不盲目增加神经网络、PPO或价值模块。
