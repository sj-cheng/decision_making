# 首捕后的障碍感知拦截引导（2026-10-24）

固定 O/PPO 第2048局；不训练、不改环境或奖励。仅真实首捕后的一追一逃搜索调用启用引导，首捕前树内跨捕获不启用。

五组 B=O旧搜索，S=O同步搜索，P=S+根拦截候选，R=S+引导rollout，PR=两者。追捕1000模拟，深度100，βπ=.5，βv=0；对手Search Only 3000模拟；逃逸完整O配置。

可见图：障碍外侧角点及场地内侧四角/边中点，偏移.05捕获半径。边不穿过障碍，代价ceil(max(abs(dx)/ux,abs(dy)/uy))。仅引导路径使用该保守路由，模拟器仍沿用原末端碰撞规则。

逃逸目标需2步以上、剩余时间内可达，按TP−TE排序，选最多3条初始方向间隔30度的路线。预测步数1/2/4/8/12/16/24；选追捕可提前到达的最早预测点，否则迟到最少且剩余时间内可达的点。无拦截点则追向当前逃逸位置；平分按节点顺序。
