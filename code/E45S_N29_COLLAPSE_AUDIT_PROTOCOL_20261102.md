# E45-S N29 退化只读审计

先进行无优化更新、无新增环境对局的诊断。读取 N 原始静态可见任务的检查点、训练逐局转移与已保存评估轨迹，不改写任何旧文件，不事后改写旧门槛失败。

N 的静态课程是初始目标可见、目标静止，后续仍使用原实际传感器；不是全程穿墙可见的全状态任务。本轮保留其物理及信息条件，不将它当作完全可观测证明。

1. 核对 N29 全部43批训练记录的动作、active、成功率、实际移动、安全缩幅、可见比例、回报及累计成功轨迹转移占比；核对未满回放容量时是否存在淘汰。
2. 从每条完整训练轨迹等间隔选至多4帧，再按早期0–6k、掌握6–12k、下降12–15k、后期15–22k四窗等间隔各选至多192帧，作为固定公共状态锚点。选样不按成功失败过滤。所有待比较模型使用同一锚点；记录每帧来源。
3. 比较 N29 的0/10215/20568及 N17 静态阶段全部存量检查点的均值、潜变量std、动作饱和/停留、安全缩幅、双Q差异；同一 Critic 对各 Actor 的联合动作作交叉评分。比较统计不构成动作优劣或因果证明。
4. 对每个检查点已保存的12条静态随机评估轨迹，重构公共特征并逐帧校验信念。使用实际记录动作计算双Q，与同策略有限时域软Monte Carlo回报比较，优先报告每对局起始状态误差。
5. Q 的比较对象为训练塑形回报加未来熵项，而非直接与原始双捕分数比较。为避免tanh边界动作反推潜变量的截断误差，在每个已有状态用冻结模型32次采样估计期望logπ；这不执行新环境动作，不更新模型。退休Actor熵为零，终端不bootstrap。
6. 仅有0/10k/20k完整检查点，不能凭两个端点声称价值误差一定先于动作退化。若无法定位，保留不确定性。只有明确线索支持时，才另行登记一个因素的短对照，不自动开学习率/奖励/架构网格。

所有审计输入在前后核验SHA256。脚本和结果在新目录保存。运行置于 `tmux:train` 的独立窗口；旧进度窗口删除前保存屏幕和终态，保留训练/模型文件。
