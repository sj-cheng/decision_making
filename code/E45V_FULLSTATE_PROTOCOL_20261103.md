## 奖励和终点适配

原始效用仍为每步 `double_capture − .0025`。训练奖励为 `raw + Phi(next) − Phi(current) − .05*blocked_fraction`，gamma=1，终端Phi严格0。Phi为`.05*当前真值目标无分配几何path势 + .25*捕获进度`，这是明确的**特权状态奖励适配**，不是J的公共belief后验平均势。如此训练奖励依赖当前完整状态，且势差望远镜；blocked动作代价仍是额外目标，不能声称全部训练奖励与原效用完全等价。选模/最终结果使用原始效用和原始捕获指标。

真实有限时域不bootstrap。`use_proper_time_limits=False`，done与term均为真正团队终止，n-step在首捕仍继续，在双捕/真实时限停止。终点next_obs保留真实state，阻断由done/term承担，而不是伪造新的可行动状态。
