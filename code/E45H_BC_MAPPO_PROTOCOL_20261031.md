最初10个更新仅训练critic，actor与std严格保持BC权重；这些环境步计入200万预算。之后纯MAPPO微调，无BC辅助损失：PPO clip.2、5 epoch、batch512、GAE gamma1/lambda.95、Adam eps1e-5、学习率3e-5线性至3e-6、熵系数.001至.0001、梯度范数.5、PopArt。保留原团队双捕终端奖励、每步-.0025与eta=.05公共几何势差，不新增单捕或专家奖励。
