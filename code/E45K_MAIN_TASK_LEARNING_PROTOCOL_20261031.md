# E45-K1：隐藏主任务可学习性与捕获信用对照

用户授权直接执行“第一步，解决主任务学习能力”。本轮是训练/验证开发实验，不生成、不读取新旧测试成绩作选模；不冒称完成强MARLbenchmark。先隔离训练反馈，再按开发证据决定是否改变表示/优化。

## 问题与固定对照

当前J训练目标的双捕奖励加终端归零势差，首捕势差在整局回报中会抵消；未双捕轨迹仍缺少明确部分完成信用。这是待检验的机制假设，不预先断言唯一根因。

种子17/29分别从J的RMAPPO latest（约50万步、按固定终点而非测试成绩选择）读取同一actor/critic和优化器。每种子两臂：original_reward继续J奖励；capture_credit把双捕完成的1替换为每次捕获0.5。完成双捕的总事件奖励仍为1，仅首捕为0.5，均无捕获为0；时间成本、公开势差与非法意图成本不变。该变化改变失败轨迹的训练目标，明确不称纯策略不变塑形。部署不增加指派、角色、搜索或专家回退。

四模型均额外最多100,000团队转移，完整24局批次允许轻微越限；总新增约40万步，之前J各50万步另列。原844维公开输入、64宽GRU、作者PPO5epoch/2minibatch、chunk10、gamma1/lambda.95、ValueNorm/PopArt关闭均保持。新学习率1e-4线性至3e-5，熵.002至.0005，两臂相同；最初3次更新只更新critic，交互计入预算。它是共同新开发训练制度下的奖励对照，不称原J逐位延长。

## 数据与环境

在J沿用的480训练历史中，按地图族×入口模式×速度分层，每格按id排序取前两组，共36组；不看任何控制成绩。前一组作为18组训练探针。保留原12组验证历史。训练是真实隐藏历史接管、80步总时域、捕获双方退场；不做全可见替代，不改变RootPUCT3000。训练每24局固定18局RootPUCT、6局固定D；同种子两臂按相同episode序号使用相同地图/世界/环境种子。策略改变后对局长度不同，步数上限附近各臂可有不同episode数，如实记录。

所有方法使用J-01共同公开信念适配，actor仅公共信息、critic训练可用目标坐标；支持再次耗尽或软件异常停止并保存现场，不丢弃继续抽样。训练全轨迹压缩存档并记录SHA，每局进行原公共重放核对。

每0/25k/50k/75k/100k（以跨越阈值的完整批次为准），评估18训练探针×AB×两对手＝36局；12验证组×AB/BA×两对手＝48局，共84局/检查点。均为完整对局，原始双捕/效用/失败成本评分；按验证两对手平均原始效用选最早最佳。训练探针只能说明训练内掌握，不能冒充泛化。已有验证集被长期使用，结果仅开发用途。

## 诊断与判读

记录分对手训练/验证双捕、首捕、原效用、动作幅度、缩幅、critic RMSE/解释方差、优势尺度、熵、梯度与PPO ratio。验证部署固定为确定性，与J一致。

开发能力门槛：选中策略两种子各自训练Root探针双捕至少50%，验证Root两种子平均至少25%。门槛仅用于判断是否已经获得可继续开发的主任务能力，不是成熟强基线、收敛或统计显著性标准。还必须比较初始和原奖励对照、固定D是否退化，不能只看门槛。单次单元36/48局小样本，不声称新独立确认。

两臂接近说明额外训练/重复任务本身可能起作用；捕获信用更好才支持本开发制度内该目标改变的收益。若都弱，优先检查表示/价值学习和隐藏重发现；若训练强验证弱，优先处理泛化。不得按结果事后改变此轮预算或删除失败种子。

## 执行与保存

GPU2/3、四训练进程各12采样物理核＋1更新物理核，总52核；不停止其他任务。单线程采样，完整对局后GPU更新；验证与各自训练串行。在线计时仅开发负载参考，不作实时性能主张。每批保存优化器、RNG与进度，原J代码/模型/数据保持只读；源码、上游、输入与初始化权重SHA注册。进程加锁，父进程退出终止本轮子进程，协调器墙钟上限8小时。

独立smoke目录使用两训练历史、一验证历史、两局完整采样和一次GPU更新，覆盖两奖励×两种子；不截断对局、不当学习收益。正式训练仅在单元检查与真实smoke成功后启动。
