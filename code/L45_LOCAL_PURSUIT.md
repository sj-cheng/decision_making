## 冻结协议

- 一追一逃，其他机器人失活；原按轴位移动力学、奖励、严格距离 `<1` 捕获，80 步；统一开启线段碰撞。
- 地图 [-10,10]²。open 无障碍；corner 一个矩形 x[-1.5,1.5] y[-3.5,3.5]；multipath 两个矩形 x[-4,-2]/[2,4]，y[-4.5,4.5]。
- 确定性 360° 距离 6（含边界）+ 障碍遮挡的独立位置观测器；不改原 64 束接口，不直接测量速度。
- 60 个几何抽样新初态，三类各 20；每类按 1.1/1.3 交替各10，逃逸每轴限幅1。初始距离3～6且可见，初始速度/加速度为0。独立工程状态单独生成；历史场景、smoke、场景银行纳入物理去重。
- L：最后位置，抵达后按最短路径步数选择最近未巡访的可见图节点，固定索引破平分。
- G/T/V：同一64粒子 bootstrap 位置滤波，按公开每轴动作能力均匀预测，剔除非法点、穿墙和空观测可见点。退化后从最后测量沿合法路径逐次应用历史空观测恢复，使用512个辅助样本，返回64粒子，最多8次重启。滤波随机流独立于搜索流。
- G：固定1×1网格的最大质量格子，固定网格顺序破平分，选择格内距中心最近的样本，沿最短步数绕障路径按能力执行动作。
- T/V：相同 root-sampled open-loop UCT (C=1)，渐进扩展 ceil(2 sqrt(visits))，相同逐深度回传、无折扣、无价值截断、无网络、无信息奖励，深度≤100且≤真实剩余步数。模拟粒子只通过模拟观测进入控制器；未观测采样目标不传给追捕控制。模拟对手的公开传感器为全位置观测，匹配信息占优条件；其低成本逃离/均匀混合 rollout 不读取本步追捕动作，不等同于原3000次搜索对手。
- T 根50% G方向（每轴高斯扰动σ=0.1×限幅、非法回退原动作），50%合法均匀动作；V只替换引导半部，三类有效意图等概率。其他节点全部使用同一G/均匀混合策略，动作树按历史而不按观测分支。
- V 每次真实决策只生成一次：追击最大质量格；重新观察用“可见粒子质量/路径步数”最大节点；出口按“追捕者到假设的最短绕障路径首转折”归并粒子，并要求追捕者到达不晚于该粒子，选合格质量最大节点。节点顺序为矩形次序、角点x/y次序、8个固定边界点，偏移0.05；平分取先出现节点。到达步数为每段ceil(max轴位移/轴限幅)相加。
- O：全状态直接G，单独标记，不参与继续门槛。
- 真实逃逸者原Search Only，3000模拟、深度100、全状态、无网络/价值。双方从同一决策前状态计算，独立随机状态再联合推进。
- 每场两配对流，共600请求；单进程单线程，按场景轮换方法顺序。T/V 50ms包含滤波、候选和搜索，最多1000模拟；在完整模拟间检测截止，实际超时据实报告。不让低成本控制等待。预热和静态公共图构建在决策外；先用独立工程三类地图各五组完整对局估算吞吐。
- smoke 独立目录，三地图×五组×一流=15局，预算3；不使用正式结果调参。
- 两流先场景内平均，再分地图配对 bootstrap 10000次，种子60020261024。比较G−L、T−G、V−T、V−G，完整报告区间及配对局挽回/丢失。
- V相对T/G均≥5点捕获提升，非法增加≤2点，开阔捕获下降≤5点才能进入独立验证。O不算上界，开发门槛不算效果确认。不更改部署推荐，不扩增测试集，不自动启动下一轮。
