# E45-T：Critic学习率单因素稳定性短对照

## 依据、假设与局限

S只读审计发现N29在约10k到20k退化过程中，同策略起始软Q减软Monte Carlo回报的均值由0.0806增至3.0114；20k的12条评估对局误差均大于2.31。潜变量std没有归零；回放未满50000且成功样本仍在。该证据支持检验价值学习稳定性，但不能确定Q漂移先于Actor退化，也不证明Q高估是唯一原因。

只检验一个因素：将Critic Adam学习率由5e-4降至1e-4，是否能在后续短训练中减轻策略退化。新实验不保证降低学习率有效，不据此预选赢家。

## 固定两种子、固定父状态

- 种子17/29，按统一时间规则取N静态阶段**首个已保存且步数>=10k的检查点**：10149/10215。不是各自最好模型；N29旧20k门槛失败记录不改写。
- 两组original / slow_critic分别完整恢复同一父状态：Actor、双Q和双目标Q、Actor/Critic Adam动量、Replay内容/指针/采样RNG、Torch CPU/CUDA与NumPy RNG、作者更新计数及采样iteration。
- original保持Critic学习率5e-4；slow_critic仅将Critic优化器学习率及对应critic_lr元数据设为1e-4。Actor学习率5e-4、alpha=0.001、gamma=1、奖励、网络、UTD=1、采样及生命周期规则保持一致。没有教师、BC损失、预设角色或分配器。
- 两组均不重置优化器或探索std、不清空回放、不重新随机热身。目标网络更新规则保持原样。

## 任务与预算

使用原N同六个初始可见、目标静止的固定任务，仍使用真实传感器；不是全程穿墙可见，不进入动态/隐藏课程。本轮检验基本技能保持，不声称解决原隐藏Root主任务或证明泛化。

正式每路新增5000在线转移，共四路约20000。每批12个完整对局，终点和每1000步的检查点按完整批次跨界，最多超出一个12x80步批次，实际超出完整计费。每个新增转移一次作者RL更新，无额外更新或成功率启动门槛。

采样继续N原始N_order、N_actions种子公式和父iteration。首批轨迹应与N原始父检查点后首批存量轨迹一致；除已有P验证过的等价float64环境速度舍入记录外，不改变物理执行。原N初始化和先前训练成本另列。

每次0/1k/2k/3k/4k/5k位置评估：同静态6条确定性、12条随机执行，无隐藏探针、无教师。保留所有检查点及两个种子，不挑最好分，不在看到结果后追加预算。评估本身不改变学习进程的RNG。

最终另用已保存的随机评估轨迹检查软Q校准是否改善；未来熵项与训练塑形奖励口径跟S一致。只有性能保持与价值误差同时改善，才支持继续扩大稳定性验证；单种子或单次高分只作线索。

## 工程核验与执行

正式之前四路smoke使用同一完整父状态和同六个任务、每路一批12对局但只执行2次新增GPU更新；这不是性能实验。审计：初始模型与RNG相同，优化器除critic_lr外完全相同，Replay文件逐位相同；初始分数与N同检查点相同；首批两组轨迹以及N存量轨迹相同；Actor/Critic均实际更新；恢复后下一次更新逐位复现。

固定4路x12采样worker+4学习进程，52个物理核；默认使用原N的GPU1。全部置于tmux:train独立窗口。源码、协议、父状态和任务hash冻结，父文件不改写。4小时墙钟上限，软件失败停止保留日志；不自动调整科学配置。

该5k实验只能判断一个步长干预在这段已知退化区间是否有用。即使有效，仍需更多种子、新任务、长期保持与隐藏迁移验证；如果无效，保留负结果，不改称已经确立因果。
