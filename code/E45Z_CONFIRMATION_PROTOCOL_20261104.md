# E45-Z 独立开发批次复核（长参考生成前固定）

目的：复核旧六地图上临近首捕的局部正向线索，不进行策略、Critic、模型集合或叶值训练。不是确认性新颖性研究，也不是满足实时预算的新算法。

## 数据与收集

纳入W开发库中全部6张未用于X/Y/Z的地图，且ID、原始地图几何与X全部12张训练/开发地图均不重复；三类布局各2张。不读取W封存测试，不挑选旧Z成功案例。地图只对X/Y/Z是新批次，W训练过程已使用整个开发库，因此不冒称从未接触的最终测试。

每地图AB、BA各1条冻结Single17源轨迹，真实对手为原RootPUCT3000。每条保留交接根及首个后续公共临近首捕根，沿用X公开规则（双方均完整；信念质量>=.35落在既定可达距离内）。若没有临近根，登记缺失，不替换地图/轨迹。最多24根，AB/BA与两个状态层不是独立地图。所有候选由原X固定函数产生：均值、3随机提议、停止、均匀，去重与补齐至6；安全接口不变。

源轨迹的真实目标位置另存private_support_audit，仅作支持几何检查。Actor与选择器只读取公共根，选择完成后才读取侧文件计算最近正质量支持距离及半径1/2/4内质量。它们不是具有标称覆盖率的置信域，不能宣称据此完成后验校准。

## 冻结的选择规则与独立评分

直接调用不可修改的Z worker：D预测128世界；Root参考32个当前世界各4个搜索随机流；各自用同一六候选、一步捕获/距离几何评分的均值argmax选择。平分时沿用numpy第一个最大项。收集/选择参数、奖励权重、Actor和安全规则均不调优。选择器内的状态来自公共D先验，Root对手在模拟器中可见假想全状态，不能把它作为可部署公共预测器。

所有状态的两种选择及文件哈希统一冻结后，才生成任何长参考回报。每根16个新后验世界；两动作共享初始世界、逐绝对步对手随机流和Actor随机流。首步执行干预动作，其后使用同一冻结Single闭环至结束，原始效用为双捕减0.0025每物理步。若两规则选同动作，只物理续跑一次，两个臂均保留、配对差为零。所有六候选及其公共输入均保存，长参考仅为被选动作评分，不用标签挑六候选最优。

16是降低旧8世界噪声的本轮预算，不能当作统计充分性保证。新命名空间与旧Z选择及X长参考分离。主要结果仍是后验世界中的一次动作干预效应，不是新控制器整局成功率，也不等于实际源隐藏世界的效应。

## 分析与停止

主指标：临近首捕层Root参考规则相对D规则的原始效用差。先在每张地图内部平均两个源世界及全部16参考世界，再地图等权；辅助报告双捕差、交接层、每图、每布局结果与缺失情况。地图簇bootstrap10000次95%区间；6个地图簇和一次开发批次不能支撑强总体结论。禁止反复换随机种子选最好成绩。

资源升级规则预先固定：有效临近根覆盖至少4张地图、主指标点估计>0、地图区间下界>0、超过半数有效地图正收益、至少2类布局均值正收益，才允许讨论一次低成本公共预测修正的小验证。否则不扩展此实现、不追加长训练；预算规则不等于算法大类失败证明。若升级，也必须之后检验真实预算下的收益，不能把Root调用成本从账单移除。

## 工程与算力

先进行地图排除、配对一致性、地图等权和升级规则的测试；只在旧训练地图完成全流程GPU3冒烟，然后冻结源码哈希运行新开发批次。正式任务位于tmux:train，至多32个单线程进程，绑定CPU48–55及56–79，所有新CUDA上下文使用物理GPU3。这里测诊断效应，不进行并发环境下的公平实时算法计时。保存物理步数、唯一参考局数、选择器Root调用数、所有失败与源/Actor/根/选择哈希核验。
