# 搜索价值验证：观测反馈与明确停止条件

2026-10-26，Asia/Shanghai。方案在本轮完整对局结果生成前登记。独立研究版本，不训练网络、不生成教师、不修改部署。既有D、G/T/T+Geo及rollout修正的全部结果保留。

## 唯一研究问题

在相同根信念、候选、目标转移、奖励与规划时长下，让未来动作依赖模拟传感器观测及其条件信念，能否比开环搜索和强G获得有用收益？

原始T不是完整NTE。新OL/FB也不是NTE复现或新的神经算法。本轮是一次有上限的搜索机制可行性检查，不能把失败外推到所有MCTS。

## 方法与信息边界

- 真实在线估计器统一加载已冻结D；同公共历史、同种子时其64输出和RNG必须逐位一致。模拟不能修改真实D。
- 新搜索根联合分布仅由64带权样本及其条件隐模式组成，重复格点质量累加；不是完整D格点后验。
- 在每个真实决策内固定根D诱导运动图。精确计算全格点×9模式的预测；FB用真实几何传感器的正/负模拟观测条件化。正测量只揭示位置，不揭示模式。
- 树内Bayes后验不是D的重置实现：D正观测会清图并在下一隐藏帧重锚、模式重置均匀。这里明确区分在线估计与固定根生成模型下的规划后验。
- OL与FB共用代码：OL不按观测分叉、不条件化预测；FB按(action,visible-position-id/empty)分叉并条件化。树内UCT和几何续跑只读取所在公开模拟历史的信念/测量。隐藏采样位置与模式只进入目标转移、传感器、捕获和奖励。
- 根候选共用原强G全部合法几何候选；深层候选共用合法九方向；每模拟最多扩一节点；续跑共用原G评分函数，FB可根据模拟公开测量追踪。不得以当前单个隐藏样本代替信念。
- 规划8个物理步（剩余不足则截断）；首次重发现+1、捕获+1、折扣0.95；目标模式0.9保持/0.1均匀重置以及原边转移概率不变。不是靠加深或改奖励寻找收益。
- 独立模拟RNG、信念导出RNG；按完整公开模拟历史缓存，不用仅自身位置缓存动态信念。空概率观测为显式工程失败，不回传零收益或补真值粒子。

## 预算矩阵

G、OL200、FB200、OLH、FBH。前3种允许200ms；H允许2000ms、最多4096模拟；200版最多1000模拟。
两种预算均从初始化/历史载入扣除首决策额度，计入估计、候选、信念更新、树和几何。G不强制等待。
H为诊断参考，超过1s高层周期，不能作为实时部署版本或最优性上界。固定模拟数重放另作工程检查，不代替等耗时比较。
记录实际返回、初始化、超时、完成/中断模拟、合法根候选访问、信念支持、预测/条件化/几何成本。部分中断模拟不回传。

## 两类目标及匹配限制

1. matched：仅从公共根64联合分布独立抽取位置/模式，不能把原A/B隐藏真值吸附到格点。M0/M1两次抽样在所有方法之间固定。目标在接管图上按同一target_step运动，不响应追捕动作。**严格的转移匹配只声明到首次重发现为止**；之后继续记录捕获，但D可能重新锚定，不能把后段捕获称完全模型匹配。D负观测guard与exact sensor差异保留，不宣称其根概率已校准。
2. rootpuct：保留原A/B真实初态、原RootPUCT、3000模拟、深度100、无网络、全状态。双方基于同一决策前状态各自选择动作，再联合推进；对手不接收本步追捕动作。原独立非法对手动作停止盾共同使用并报告。

matched的主要终点为失败惩罚首次重发现时间；RootPUCT为失败惩罚完成成本。另报合法捕获率、重发现率、成功步数、再次丢失、完整时延及失败现场。
失败惩罚均为接管时剩余步数；不能删掉失败后计算均值。matched初态与RootPUCT初态不要求相同，只要求每个对手条件内部五方法严格配对。

## 数据、门槛和停止

工程先行：独立概率矩阵/观测条件核对、合法模拟、无真值动作依赖、在线D不被模拟改变、固定数精确重放、预算与部分模拟不回传。

开发：旧closed-loop银行每family取H4/v1.1、H6/v1.3的第一个变体，共6公共历史×两世界×两对手×五方法=120完整对局。不依据输赢选择或调整版本。
确认：种子84020261026生成3family×2H×2speed的新12历史；A/B或M0/M1×两对手×五方法=240局。几何验收与公共历史去重后在开发完整结果前冻结。不得依据算法表现拒绝地图，确认只运行一次。

四项主要比较：FBH−G、FBH−OLH，各在matched/RootPUCT内。按公共历史分组bootstrap10000次、seed84120261026，保留组内两世界/两对手/五方法相关性。四项相应主成本差用共同max-centered同时95%区间；其他差值普通区间作为描述。

**开发继续门槛**：任一对手条件下，FBH相对G及OLH的对应主成本点估计均至少减少1步，且matched重发现率或RootPUCT捕获率均不下降，且零工程失败，才运行完整独立确认。否则停止本次搜索方案，确认银行保留未使用。开发门槛是资源筛选，不是显著性证明。

**确认收益门槛**：同一对手条件下两个成本差同时95%上界都<0，观测成功率均不下降且零工程失败。捕获/重发现的“观测不下降”仅是小样本探索性筛选，不是统计非劣；全成功bootstrap退化不能证明等效。

最终分别判断：工程未通过；高预算未确认收益；只在匹配诊断有线索而未迁移；高预算在真实对手有效但200ms不足；200ms也有可靠收益。
仅RootPUCT高预算同时胜过强G和同预算OL，才支持随后另立神经扩展研究。即使通过也不自动训练。本轮若不通过，停止该具体版本，不自动加价值网络、奖励、深度、PPO、对手模型或其他模块。
