# 唯一机制：rollout按模拟自身位置重算G几何动作

2026-10-26，Asia/Shanghai。D与原G/T/T+Geo和历史结果冻结。
新增独立研究类T-R、T+Geo-R，仅将树扩展后的重复根位移改为按模拟追捕者当前位姿调用原G几何函数。
使用当步根64带权信念快照、原地图与几何函数，不在rollout中添加新滤波或未来观测分支。
函数输入不含模拟目标位置、意图或实际环境；目标样本只供原运动核、传感器、奖励及终止判定。
根/深层候选、UCT选择、树深度8、奖励（首次重发现+1、捕获+1、折扣0.95）、D模式转移、根权重、真实对手均不改。

## 计算与工程边界

相同真实200ms入口到返回预算、最多1000次模拟，允许低成本G提前返回。
重算G的结果可按模拟自身位置的精确浮点二元组缓存；只在一个真实决策内使用，不能跨观测复用或量化坐标。
缓存命中与不命中输出必须逐位相同。缓存仅节省重复几何计算，既有树和模拟抽样不变。
每步检查剩余时间；不够完成一次几何查询时不启动该查询。预算中断的部分模拟单独标记、不回传伪终局值。
所有部分模拟已执行转移仍保存并独立核验，不计作完成模拟。真实总时延含估计、建图、候选、缓存、搜索和最终检查。
首次接管的地图/加载及history[:-1]初始化也占首次200ms预算：五方法共同扣除已用初始化时间，把剩余时间交给当次act；后续每步恢复200ms。原算法源码不变，首次扣费与各项原始耗时单列。
缓存、时间检查及Python/Numba边界开销全部计费；原版不改。相同预算对照为主要实践指标；固定完成模拟数只作工程/机制辅助，不伪称等耗时。
