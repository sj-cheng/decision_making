# E45-Z：位置不确定与对手转移失配的一步校准

在查看本轮结果前固定协议。不训练 Actor、Critic、叶值或模型集合，不读取 W 封存测试。复用 X 的47个公共状态与固定六动作：6张训练地图和6张已用于探索的开发地图，各含交接和公开临近首捕分层。不能将复用开发地图称为新测试。

每个公共状态以同一 D 公共后验采样32个当前位置世界；每世界独立执行4次 D 转移和4次原 RootPUCT3000。Root 只看到模拟器内的假想当前世界；同一敌方同时动作复用于六个追捕动作，不能看到追捕动作的未来结果。D 前瞻另采128个独立世界。状态均核验与公共观察一致，双方转移均检查物理合法性和捕获退休，非法 Root 动作按原接口停止并计数。假想世界不是源轨迹的真实隐藏状态。

分析项：

- 精确计算 D 内部全方差分解：固定当前位置后仍有的模式/运动随机性，与位置混合造成的方差。这是 D 内部恒等式，不能宣称真实失败的因果分解。
- 固定两个目标当前位置，仍边缘化 D 模式，比较条件均值与 D / Root 重复转移。重复样本校正条件均值偏差平方，保留负有限样本估计；匹配 D 对照用于识别采样误差。位置特权仅用于离线评分。
- 比较捕获、退休、存活可见等8类事件的概率 MSE 与 Brier；后者包含不可约随机性。连续分布差异在位移空间用经验能量距离刻画，并报告同样簇设计的 D 对照。
- 以固定六动作的一步捕获加距离几何代理检查动作相关性。32个当前世界按奇偶分半：一半选动作，一半评估，双向平均。代理收益不是整局效用、最优 Q 或双捕率。

先报告交接 / 临近首捕两层、开发地图等权均值和地图簇探索性区间，原始已知/隐藏目标误差另存。六张复用地图、同一 Actor 候选池、不校正多重比较，不能作为确认性显著性检验。

停止与升级：单纯 D 与 Root 不同不足以启动新模型训练。需要预测偏差超出匹配对照且确实影响决策，再限定单一后续机制。即使通过，一步校准也不能证明多步收益、先验对真实隐藏状态的覆盖、新颖性或闭环成功。

工程：先通过公式与物理事件测试、两训练状态 GPU3 冒烟，再冻结源文件与输入哈希并运行正式诊断。32个单线程 CPU worker 绑定48–55和56–79；只有父进程分配 GPU3 上的距离计算，避免32份 CUDA 上下文。CPU参考生成与GPU误差计算顺序执行；不属于搜索计时实验。所有正式任务放 tmux:train，未修改 W / X / Y 冻结源。
