# E45-B：无预设分工的局部信念联合NTE

2026-10-27，Asia/Shanghai。用户已授权实现、在服务器tmux train会话运行并提高并行度。此协议在新训练和测试产生前冻结。原E44、E45-A源码、模型、协议与数据保留并检查摘要。

## 要检验的问题与边界

两名追捕者只读地图、自身团队位置/存活状态、合法共享局部观测历史和每目标D信念。主方法直接生成(aP1,aP2)四维连续动作；无AG预分配、无“追击/封堵/观察”角色标签、无G动作教师或G动作回退。AG和IG仅在评测中作为强基线。允许合法性拒绝和停止。输入的两车槽位不是固定角色，训练中交换追捕者与目标槽位；不能仅凭类似包抄的轨迹宣称协同涌现。

本阶段仅追捕团队迭代学习，对手是冻结模型和原全状态RootPUCT3000池，不称双边自博弈或全局最优。以后加入对手历史策略池/双边学习需单独记录。D的预测核和目标间因子化仍是模型近似；不能称已解决真实对手反制失配。

环境继续使用原Example8同时四车推进、闭矩形扫掠碰撞、距离<1一对一捕获、捕获双方同时退场；首捕后成为1v1。追捕速度每轴1.1/1.3、逃逸1.0、dt1、时域80。无新增机器人间碰撞模型。共享传感器半径6、360度、无遮挡、无噪声、已知目标身份、通信无损无延迟。

## 数据与完整预算

24张训练、6张验证、18张测试地图，三类既定拓扑，各有同入口、对向入口、队形错位的合法脚本历史。增加长短壁障和速度变化。两隐藏世界AB/BA必须提供相同公开历史；地图、完整历史和所有世界按组分区。验收仅用几何/可达性/传感器与物理合法性，不按AG或学习方法输赢挑图。这是新实例泛化，非未见拓扑。

训练种子17、29、43；12轮策略迭代，每轮每种子24个完整训练对局与6个完整验证对局，共1080个采集对局。前4轮训练对手为固定D根运动核，后8轮在该核与RootPUCT池间平衡；验证始终包含两条件。固定核只在每个目标首次重发现前保持生成核匹配，后段不称全程模型匹配。

每轮每个种子以该种子上一轮Joint模型进行400ms联合MCTS对局采集；初始模型为随机权重，非训练成果。每局均匀保留最多32个合法公开状态，保留所有失败对局。策略标签为本状态完整模拟产生的根访问分布，保留多峰四维动作；若没有完整模拟，只标注实际合法回退动作并明确来源，不伪造搜索标签、不因性能不足删局。

每种子保留最近3轮训练回放，当前轮验证数据用于检查点选择；三种网络共用完全相同的数据与标签。训练不调用几何控制器。策略家族为单四维高斯、两车各自混合的分解提议、共享潜在分量的四维联合混合（8分量）。所有网络共享地图/两车/两目标带权粒子/历史编码和团队价值头，参数量在看结果前取最接近65000的隐藏宽。分解提议仍进入联合树，比较的是动作相关性，不冒称去中心化独立规划。

每轮九模型各30 epoch，Adam lr3e-4/weight_decay1e-5/batch128/梯度范数10；模型暖启动上一轮检查点，Adam每轮重新初始化；相同数据/随机批次与槽位交换增强。损失=四维Cartesian访问加权提议NLL+.5团队价值Huber；每个模型按自身最低验证综合损失选中该轮检查点。仍执行全部30轮，没有提前停止。12轮共108次模型拟合、3240个seed-epoch，最终九个新训练检查点；不能把这些数当独立对局。GPU确定性设置记录在配置/日志，在线使用导出NumPy权重。

没有教师性能或胜率屏障；即使未胜基线也完成全部轮次及测试。信息泄漏、非法物理、非有限损失、文件损坏是工程错误，保存现场后修复，不冒充负结果。

## 团队目标、冷启动与价值

原始团队奖励：仅双捕完成当步+1，每个实际物理步−0.0025。价值目标来自实际对局完整后缀回报，非G标签或隐藏位置监督。因此优化的是双捕和效率，不给个人目标或特定角色奖励。

采用显式公共距离势函数处理稀疏奖励冷启动：Phi为每个活跃目标的信念期望“到最近活跃追捕者的绕障步数”的负和，距离各截到80；eta=.05。它只返回标量，不输出分配或动作。每步r_shaped=r_raw+eta(Phi_next−Phi_now)，成功和超时的终端Phi都为0。完整对局的shaped总回报=r_raw总回报−eta*初始Phi，故给定历史的完整任务排序不变。网络价值拟合从当前状态起的shaped后缀；搜索新叶调用该公共价值。这个方案具有明确几何标量先验，不能声称“完全无人工先验”。短搜索和不精确价值仍可能受势函数影响，须在结论中限定。

## 联合搜索与信息合法性

共享公开节点包括两车位置/存活、两目标条件信念、联合观测历史。隐藏索引和模式只在生成器中采样，用来推进目标、生成观测与捕获事件，不能作为提议/选择/价值输入。根导出64带权分布；树内对每个目标保持固定根图上的精确模式数组，并按所有活跃队友传感器条件化；目标间仍是因子化近似。正观测按合法可见网格位置分支，负观测共享相应信息集，不按隐藏世界拆树。

一个候选是两车四维联合动作，一个物理转移同步推进四车，随后按原配对规则更新退场状态和观测。最大物理深度8；新叶使用团队价值截断。UCT c=.1；渐进扩展min(16,max(2,ceil(2(N+1)^.35)))。提议75%网络+25%无角色均匀，均匀分量有50%按每车最大轴投影到速度上限，2%全停；所有保留连续速度和停止的支持。最多64次合法性拒绝，无法形成合法提议或没有完整搜索结果时返回合法停止，明确记录。

## 资源、时延与持续运行

最多32个CPU单线程进程，绑定不同物理核；网络更新最多两进程使用当前空闲GPU2/3，避开其他GPU任务。CPU对局池与GPU拟合阶段串行衔接。总墙钟预算12小时，起算点和已完成对局/标签/epoch检查点可恢复；断开本地连接不影响服务器tmux。性能不触发中途停止。

与E45-A冷接管计时明确区分：地图/模型构造单独报告，接管前脚本历史按真实物理步逐帧吸收并逐帧记录时间，不能把这些耗时删掉。持续在线act从当前观测起，完整包括D更新、动态模型构建、公共特征、网络、搜索、检查及返回，共享团队200ms墙钟；训练阶段另为400ms。存在不可分割操作时，任何超时均据实记录，不能据此声称严格200ms通过。

正式测试前，以验证集36个两步请求做串行/并行校准，仅使用时延、CPU/墙钟和模拟次数选择32/24/16/8/4或串行，不用捕获率选并发。要求CPU/墙钟比>=.85，模拟次数比>=.75，超时比例相对串行增幅<=.002。记录并发负载下的真实返回时间，不冒称串行时延。

## 最终1512局与消融

18独立测试历史×2世界×2对手×21执行臂=1512完整对局。执行臂为IG/AG/无网络联合树U三个单例，以及Single、Factorized、Joint、Joint-Direct、Value-U（同Joint价值、均匀提议）、Prior-only（同Joint策略、无学习价值）六家族各三种子。所有学习模型在测试前冻结，不按部分测试重训。Direct不做MCTS，无G决策回退。对所有方法报告双捕、首次捕获、失败惩罚完成成本、团队效用、完整时延/启动/历史与合法性；三种子不增加独立地图数。

预定主要比较为Joint减AG/Factorized/Single/Direct/Value-U/Prior-only六项，分别在两对手条件下形成12项。主要终点为真实团队效用（正为好），18个公共历史成组配对bootstrap10000次，保留组内世界和训练种子，用12项最大中心化偏差给同时95%区间。可靠收益要求同时下界>0、效用差>=.01、三种子均为正、观察双捕率不下降、平均完成成本至少改善1步，且两臂无在线或历史帧超时；成功率观察护栏不是统计非劣证明。成本与捕获率完整报告，不事后换主要指标。
