## 第一步：固定预算BC

种子17、29各从相同作者架构的新随机初始化训练，不继承O终点或H的其他网络。每actor固定3000次全163样本更新，作者Adam lr5e-4，无额外训练数据、容量或编码修改。损失为active归一的高斯潜变量均值MSE：mu对atanh(clip(action,-1+1e-4,1-1e-4))。不对随机样本动作回归，不训练critic。

BC开始将log_std头权重设零、bias设log(.15)，BC期间保持该头固定，使探索标准差明确为0.15；均值和共享MLP训练。Actor架构不变。记录潜变量MSE和tanh后动作MSE，不用拟合误差替代闭环成绩。第二步两臂都继承同一std初始化，随后由原HASAC正常训练std。

固定0/1000/2000/3000更新检查点：同6情形确定性评估6局，随机2动作种子12局。只认3000终点，不事后改选中间最好模型。两个种子终点确定性均至少5/6双捕才通过。BC_ONLY终点完整检查点和评估永久保留，不在RL中覆盖。若失败，保存bc_gate_failed和报告，正式第二步不启动；低拟合误差而闭环差优先提示检查覆盖与误差累积，不能直接断言容量不足。

## 第二步：同BC初始化的两臂RL

replay与replay_bc各种子17、29，各新增名义20000在线团队转移，12局完整批次可略超。每种子两臂载入完全相同的终点BC Actor；actor优化器新建，critic/目标Q按相同种子新建。BC的Adam状态不继承，随机critic不冒称已经通过BC学会价值。共同的初始critic不准确可能影响技能保持，这正是本轮需观察的因素，不额外混入critic预训练。

两臂都使用25%独立固定教师区+75%在线回放，batch256，在线容量50000。只由当前随机Actor采样，首批起即用BC策略，无均匀随机动作预热；每在线转移一次作者HASAC更新，UTD1。其余奖励、gamma1、1-step、lr5e-4、alpha.001、退休、终点与安全映射沿用O。

replay不加辅助损失。replay_bc对同一163条教师公共样本加入lambda=0.1的相同潜变量MSE，整个20k阶段保持常数，不退火。通过Actor Adam的step前hook，在原RL梯度上累加lambda*BC梯度，仍只执行原来那一次Adam step。没有复制或修改作者更新器，不另做第二次优化器step；清楚标记这是监督辅助变体，不声称原HASAC无改动。hook不消耗随机数；lambda0路径必须与原作者更新逐参数完全相同。两个独立Actor各自受同一公共教师轨迹对应动作监督，无人为角色。

0/约5k/10k/15k/20k在线步均做纯Actor确定性6局、随机12局评估，报告所有检查点、终点和BC动作误差。主要观察相对冻结BC_ONLY的保持/改善，以及两臂是否跨种子稳定。原O只能作历史参考，不能与不同初始化的新臂拼成单因素因果对照。记录每模型历史示范访问成本、3000次BC/actor更新、RL在线量、梯度量和监督额外计算。
