# 墙角转向与几何分支导出：一次冻结的2×2消融

## 定位与最小干预

先精确复现旧A，分别记录完整分布的1米质量/核NLL、64样本覆盖，以及转向前后的变化。
将“旧导出遗漏但仍有≥1%局部概率”与“完整分布就低概率”分别计数；不把两者混为采样问题。

固定七组：

|组|运动模型|64样本导出|
|---|---|---|
|P|原64粒子|原随机重采样|
|A|前轮固定方向意图|原速度模式分层|
|B|与A相同|几何分支分层|
|C|公开地图引导意图|与A相同|
|D（唯一候选）|与C相同|与B相同|
|U0|均匀可行集合|与A相同|
|U1|与U0相同|与B相同，作为候选D的强对照|

运动改动只将9种意图的固定均值替换为地图上的合法首步：目标点=最后可见位置+20×原意图方向，按场地裁至±9.95；静止意图仍为零。可见图绕障后仍朝同一个公开构造的意图目标前进，避免绕过墙角后丢失原意图。目标不是实际隐藏目标；不输入真实路线或未来位置。目标非法则明确拒绝，不临时换目标。

导出只改分层依据：按公开矩形两侧/端部定义几何区域，后验质量≥1%的区域各保留至少1个样本，其他区域合并为尾部层；剩余名额按概率分配，层内仍systematic抽样。层质量/样本数为样本权重，不能强行提高弱分支概率。全部仍为64样本。

网格0.5米、节点/合法边/可达范围、9模式、σ=.35、模式保持率.9、观测约束、奖励外部状态全部沿用前轮。所有完整分布范围一致。A/B与C/D必须逐步密度一致，U0/U1也须一致；导出不能冒充改善完整分布NLL。

## 顺序、数据与冻结

1. 定位：前轮24组确认公共历史，精确复现8/32来源；本轮只作开发。
2. 受控消融：同批96条已用固定观测轨迹，七组共同输入。
3. 全新确认：固定种子72020261025，一次生成24组（3拓扑×2遮挡档×2速度×2变体），每组A/B两个隐藏世界、上下两路线，共96条。墙高从[6.25,6.85]/[8.2,8.8]抽取；变体1在隐藏历史第3个动作增加一次合法停顿，变体0不停顿。地图/历史摘要与历史银行去重，先几何验收、再冻结；不按任何估计结果筛选。
4. 只有开发满足“D相对A核NLL至少改善0.2、墙角接管覆盖净增加至少4/32、无执行/证书失败”才读取全新确认结果；不通过则止于开发，保留未使用新银行。

不因消融排名改用B/C作为候选，不扫目标距离/σ/保持率/阈值，不在确认结果上调参或追加样本。

## 指标、归因与验收

报告64样本覆盖、完整分布1米质量、固定σ=.5米核NLL、90%名义面积/经验覆盖、≥1%几何分支保留与概率质量误差、全部祖先路径合法性、实际更新P95、初始化/地图准备均值与P95。
主要机制比较C−A（运动）、B−A（导出）、D−C（导出在新模型上）、D−B（新模型在新导出上）及交互。密度不依赖导出，故完整NLL的导出效应理论上为零，必须核验。

统计单位为24组公共历史，组内保留A/B及两路线，配对bootstrap10000次、种子72120261025。完整报告三个拓扑，不能因墙角失败而删除。普通区间与主要D−P、D−U1两项核NLL的同时95%区间分别提供。

独立确认采用门槛沿用前轮质量要求并明确墙角/分支限制：D接管覆盖≥75%、隐藏历史等权覆盖≥70%；D−P及D−U1核NLL同时95%区间上界<0；90%名义面积≤U1；墙角接管覆盖≥75%；所有≥1%几何分支均被导出；无执行或证书失败；预热后的实际更新P95≤10ms，历史初始化与建图另行如实计费，不能据此宣称MCTS满足50ms。

通过后才可冻结共同估计器，为G/T/T+Geo同信息、同实际时间预算对照准备；本轮不自动启动搜索对比、网络训练或部署。失败就明确原因与边界，不叠加模块追结果。
