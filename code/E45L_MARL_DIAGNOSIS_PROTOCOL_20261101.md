# E45-L：宏观复查后的真实隐藏主任务诊断

目标是得到具有竞争力且可信的既有MARL学习算法基线，无显式目标指派、无预设角色、actor不读隐藏目标。不以基线必须输给主方法为选型标准。L只是诊断环节，不能替代最终多种子、广场景独立测试；不据L失败就认定MARL不适用。

从J训练历史按地图族分层，各族按id排序选第一组，共3组；每组AB/BA，共6个固定环境情形。选择不读控制成绩，不换掉难例。RootPUCT3000固定对手、真实局部传感器及共同信念、原80步时域与首捕双方退场规则不变。只重复环境种子，行为采样种子每局独立变化，并与环境/信念/对手种子分开。无验证/测试历史。

先运行现有无指派GEOM_SEARCH联合搜索作为任务可达性正向控制，同6情形、200ms，不将其当理论上界或确定成功保证；失败保留，禁止事后挑易例。

两个初始化：随机权重与J固定终点actor/critic，种子17/29，共4模型，每模型新增100000团队转移（完整24局批次允许轻微超额），总约40万。两臂优化器均新建Adam，隔离初始化权重影响；不把结果归因于旧Adam。沿用J作者RMAPPO，844维公共输入、64宽GRU、gamma1/lambda.95、PPO5epoch/2minibatch/chunk10，ValueNorm/PopArt关闭、共享奖励与退休mask不变。J原奖励不改。共同lr3e-4线性降3e-5，entropy .01，前3次只更新critic且计入交互。不声称原J逐位延长。

训练24局固定情形平衡重复，每批重新打乱顺序。每0/约20k/40k/60k/80k/100k保存完整checkpoint，并在相同6固定情形评估确定性6局与随机策略2个固定动作种子12局。全部对局完整执行、按原始双捕/首捕/效用评分、公共重放核对；不选最佳checkpoint，报告全部曲线和终点。独立动作采样重复不是独立场景或训练种子。

训练内确定性双捕80%为诊断目标，对每个种子分别检查；6情形离散化意味着至少5/6。若仅终点偶然达到，不称稳定掌握，应检查最后几个评估点并扩大动作/环境种子确认。不能以随机策略胜率替代确定性部署指标，随机可作为单独既有算法执行方式开发。

保存全训练压缩轨迹、评估全轨迹、PPO指标、checkpoint/优化器/RNG、选例清单与源/模型/输入哈希。旧J/K代码模型不修改。GPU2/3四trainer各12采样核+1更新核，协调器8h上限，异常停止保留记录，独立tmux显示LIVE.txt和日志。smoke独立目录：1训练历史、AB/BA、2完整训练局及每臂一次更新，四臂均须通过再正式启动。

解释：随机权重可学J续训不可学优先怀疑初始化/优化；随机策略可学确定性弱检查分布与部署；少任务可学广任务不可学检查覆盖与泛化；两初始化均弱检查公开表示、回报传播及作者训练器适配，再考虑最多一个编码候选。此阶段上限是资源管理，不是收敛证明。HASAC作者代码的适配单独核查，不在此协议混入新算法。
