## 错误原因与独立证据

1. 审计器硬编码13维状态模板，而当前Example8的完整状态为53维（29基础维加4×6记忆特征），活动索引仍为9、10、11、12。以公开输入和实际环境维数生成完整模板后，60个matched初态全部逐位一致，附加字段均为公开初始化的0；没有读取A/B隐藏初态。
2. 审计器要求实际物理坐标永远逐位等于理想格点。真实环境先将`raw=ideal_next-physical_current`限幅至[-1,1]，再用`physical_next=physical_current+clip(raw,-1,1)`更新。1799个matched转移中26个post/26个pre比较出现最多2ULP（8.881784197001252e-16）的格点差；40帧raw因浮点舍入稍超1而发生限幅。按真实限幅算术独立递推，1799帧raw和物理端点全部逐位一致；理想/物理坐标的可见性和捕获事件翻转均为0。

v2使用实际公开环境的state_dim/active_idxs生成模板，逐位检查完整初态；同时重放理想格点采样器与独立物理递推，要求raw和物理端点均逐位一致。不放宽任何动作、传感器或捕获容差，也不以任意atol接受端点误差。
